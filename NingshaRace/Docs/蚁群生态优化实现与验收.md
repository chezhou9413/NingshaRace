# 蚁群生态优化实现与验收

## 范围与交付状态

独立捕食者蚁狮的实现与验收见 [蚁狮伏击机制与验收](蚁狮伏击机制与验收.md)。它会攻击现有蚁群，但不参与蚁巢数量和补员管理；蚁狮及此前吐酸蚁朝向、拖尾修改尚未部署。

对应本轮优化截图和用户提供的吐酸蚁三向贴图。实现驱蚁桩、共生菌巢、吐酸蚁、巨坑单口蚁巢洞室，以及采食、补员和受击反击的配套调整。

源码根目录：`1.6/Source/NingshaRaceLib`。交付采用 Release 编译和本地 Steam 模组目录部署，不启动 RimWorld，不运行地图模拟或性能基准，不提交或推送仓库。既有 MSB3270 架构警告不属于菌群配置错误。运行时结果仍需人工确认，不能把编译成功当成已经验证地图种子、战斗数值或长期供需平衡。

仅新生成的地图获得洞室、菌巢和驱蚁桩；不迁移旧地图，不给旧蚁群补算吐酸蚁上限。

| 喷酸 | 射程18、伤害30、穿甲0.25 | 实体弹丸；预热0.6秒，攻击后冷却1.12秒，两者不同 |

采收量4倍是结合现有食用菌6天基础生长期作出的配套取值，不是原截图明确给定的数值。它让温床真正提供较多食物，但严寒、疾病、玩家破坏、物流拥堵、难度产量倍率仍可导致缺粮；不赋予蚂蚁不耗食或凭空补满饥饿的特权。

### 菌群疏密的 XML 配置

编辑 `1.6/Defs/DesertPit/Ecology/NingshaRace_AntHabitats.xml` 中 `NingshaRace_FungalMound` 的 `DefModExtension_FungalMound`，不提供游戏内设置页。

| 字段 | 默认值 | 调整效果 |
| --- | --- | --- |
| `targetPlants` | `24` | 每处菌巢范围内的植物总量上限，必须大于零；调低可减少堆积 |
| `minimumPlantSpacing` | `1.5` | 植物中心的最小直线距离；允许从零到作用半径，零关闭额外间距限制 |
| `regrowthIntervalTicks` | `5000` | 补生检查间隔，必须大于零；2500为一小时，数值越大补生越慢 |
| `regrowthBatch` | `3` | 单次最多补生数量，必须大于零；调低可减缓采收后的恢复 |
| `radius` | `5` | 生长、收成加成与补生搜索的作用半径；植物只出现在合法地面，不会扩挖洞室 |
| `growthMultiplier` | `2` | 范围内植物生长速度倍率 |
| `harvestMultiplier` | `4` | 范围内食用菌的采收量倍率 |

- 调整项目内 XML 后重新部署并重启游戏，无须为纯数值调整重新编译。直接改 Steam 目录会在下次部署时被项目配置覆盖。
- 巨坑仍有两座蚁巢配对菌巢和一座独立菌巢；清剿任务仍有一座。本项调整的是每处生产区域内的菌子密度，不减少蚁群的食物来源点，也不改普通野生植物的全图初始数量。
- 初始生成与后续补生共用同一间距检查。每株生成后即时参与后续候选检查，范围外的邻近植物也要避让；无合适空格就结束本轮，不为凑数量重叠生成或无限重试。
- 数量上限不等于保证数量：最小间距越大，实际可容纳的菌子越少。`1.5` 会避开相邻八格；调到 `1.1` 可允许对角相邻，更宽松；调到 `2.5` 则更稀疏。
- 已有存档不会清除或重排现存植物。降低上限后，超过上限的菌巢停止补生，待自然死亡或采收腾出空间；读档后沿用已保存的下一次检查时间，之后按 XML 间隔运行。
- 保留原有生长与收成倍率，不自动补偿较少的菌子。高等级蚁群的长期供需需要游戏内观察，必要时单独调收成；不绕过饥饿或物流机制。

## 关键不变量

### 驱蚁桩

- 缓存物资、分配搬运、拿起物资之前都会检查实时覆盖。失效期已经派出的工蚁，在驱蚁恢复后会取消尚未拿起的物资。
- 物资已经被拿起后不会因为路过另一座驱蚁桩而凭空退回或消失。
- 工蚁采收和临时就地找食物同样排除保护区；普通移动、巡逻、战斗、侵入警戒完全不检查驱蚁范围。
- 搬起时旧位置立即失去覆盖，重新安装时新位置立即参与判定。跨地图、读档和重新安装不重置周期起点，不重抽当前周期。
- 不开放建造或复制建造，但可占领、卸下、搬运和重新安装。

### 食物与种群

- 只采收能够产出食物且非药品的成熟植物，收成是实际物品。后续搬运入库和进食仍走工作流程，不搬走整株植物。
- 普通野生菌群的初始容量统计和缺口统计都排除菌巢范围；菌巢自己维护自己的菌群，避免两个再生系统重复补生。
- 口粮支出先完整规划再执行。若尸体太大或堆叠向上取整会吃掉保留口粮，则不消费；不能先吃掉一部分后才发现付不起。
- 紧急饥饿不被警报、撤退或狂暴永久挡住；仍可通过破坏菌床、杀死工蚁或封锁物流造成断粮。
- 吐酸蚁计入常规伤亡、撤退阈值和调查队规模，可参加调查队，失巢后沿用狂暴流程。

### 洞室生成

- 只在 `NingshaRace_DesertPitMap` 与 `NingshaRace_DesertPitStartingMap` 规划两座洞室。
- 在洞穴掩码阶段生成受缓变噪声扰动的旋转椭圆和生活空间，洞体不对称、不固定为17×17方房。每座洞室独立采样大小、轮廓相位与弯道参数，选址候选不重复抽样。
- 入口由两段连续切线的三次曲线绕过洞体下侧，再回转接入主洞；圆形笔刷形成约三至五格的变宽通道，保留遮挡洞外视线的岩脊，不用直角矩形拼接。
- 三至四格左右的厚岩沿实际开放地面外扩。矩形包围盒只用于前缀和选址和局部边界计算，不整体回填矩形墙块；岩层包围的闭合小缝隙填为实岩，避免留下无法接回的孤腔。
- 通过前缀和先查询候选包围盒，存在占用时按互不重叠的岩层行区间精确检查，空白角落不影响普通140格地图的可用位置。四向区间只旋转一次，禁用区检查遇到占用立即结束；只为最终选定位置构造世界格集合。主通道交叉代价也按实际岩层计数，被截开的天然支洞沿岩层外侧重连，不要求沿矩形外框绕行。
- 外部连接使用八向岩性加权寻路，禁止斜穿两个阻挡格的夹角。完整路径生成后统一圆滑雕刻，笔刷越过保护边界的部分不落地，只提交与中心线连通的区域。
- 场景预留覆盖洞室厚壁和连接通道。塌岩、散石、天光裂隙、地貌、水系、遗迹、装饰、矿脉和普通植物不得覆盖这些保留格。
- 实体生成前检查出口截面连通且至少三格、无侧壁开口、岩层未被重连改写、巢穴及储藏环和菌巢占地完整，以及洞口外多排位置对蚁穴的视线遮挡。洞口射线检查不是全地图射击模拟，游戏内远程战斗仍需手工验收。
- 地图尺寸不足或根本无法安置时给出明确异常，不静默缺失第二座蚁巢，也不进行无限随机重试。
- 清剿任务仍使用开放场景安置，固定4/5级与禁止升级规则不变。

以下文件均位于 `DesertPit/AntColony/Generation/Chambers/`：

### 性能和显示

- 没有巢群的地图不再每250 tick扫描物资。
- 物资候选按地图缓存，距离先过滤，再做昂贵的预留、可达和储藏检查。
- 不引入 Task、Parallel 或工作线程地图修改；游戏状态和渲染对象不交给线程池。
- 自然洞室仍在当前地图生成流程内串行完成；形状每座只采样一次，寻路使用原版优先队列和局部数组缓存，只将主洞扩张边界作为多源起点。自然化寻路比固定四向最短路更复杂，未测量生成耗时，不宣称已实测提速；不增加游戏进行时的逐帧或逐 tick 生成工作。
- 仅当前可见地图、镜头内且无迷雾的生态建筑释放少量淡绿粒子。纯视觉随机数使用独立状态，不影响生态和战斗的随机序列。
- 酸液弹丸在原版 `TickInterval` 完成移动与碰撞后生成绿色尾迹，只处理仍存活且逐帧更新的弹丸；命中、护盾拦截、出界销毁及离屏跳步不继续补画。每段按约0.22格采样，最多6处，每处一团窄酸雾，间隔点缀一颗酸滴；粒子约0.24–0.26秒淡出，暂停不继续生成，不产生额外伤害或污物。
- 尾迹只在当前地图、镜头内、已揭雾的采样格创建，粒子初始化也包在独立随机状态内。使用原版 `FleckBase`、`FleckBase_Thrown` 与批量绘制，不创建新材质或 Unity 对象，不使用额外 Shader 包。颜色、淡入、停留和淡出时间直接在尾迹 XML 配置，战斗数值不变。
- 选中时显示范围圈，未选中不常驻画圈。说明使用原版自动布局，不添加固定高度自绘文本框，不修改全局字体或 GUI 颜色。

## 美术占位

- 吐酸蚁：使用用户提供的正面、背面与西向侧面原图，绘制尺寸1.9，不重新绘画或改动像素。原版 `PawnRenderNode_AnimalPart.MeshSetFor` 使用默认镜像西向的 `GraphicMeshSet`，不会按 `Graphic_Multi.EastFlipped` 自动调整动物网格，因此不能只依赖 `allowFlip=true`。专用渲染树对身体 `drawData.dataEast.flip`、`dataWest.flip` 均设为 `true`：东向把左向原图镜像朝右，西向抵消默认镜像仍朝左；南北不变。伤口、背包、泡沫及搬运层沿用原版节点，不修改全局动物渲染树。
- 驱蚁桩：暂借 `DesertPitStalactite03` 并染成偏绿石色。
- 共生菌巢：暂借 `AntNest` 缩小、压扁并染绿，周围实际菌群参与表现。
- 喷酸弹丸：暂借 `NingshaRace/Projectiles/FlyingNeedle` 染绿。后续只换相应 `graphicData.texPath`，不必重绘已提供的蚂蚁。
- 喷酸尾迹：复用原版 `Things/Mote/AirPuff` 柔边酸雾和 `Things/Mote/AcidSpray` 酸滴贴图，使用绿色调色与短淡出表现液体喷射。

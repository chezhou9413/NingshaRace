# 凝砂儿童生成说明

## 错误原因

原版调试生成菜单调用 `PawnGenerator.GeneratePawn(PawnKindDef, Faction, PlanetTile?)`，其创建的 `PawnGenerationRequest` 默认只允许 `DevelopmentalStage.Adult`。

`NingshaRace_Child` 的年龄限制是3至17岁，凝砂族18岁才进入成年阶段。因此原版 `GenerateRandomAge` 的年龄上限和发育阶段检查没有交集，300次尝试不能解决这个配置冲突。原版超过重试次数后还会退出循环并使用最后一次抽样结果，所以不能仅屏蔽日志。

此外，凝砂族全局 `ageGenerationCurve` 从14岁开始提供抽样范围。只允许儿童阶段仍无法随机生成3至13岁的儿童，也不能可靠支持低龄区间请求。

## 实现入口与边界

源码路径均相对 `1.6/Source/NingshaRaceLib`。

- `Race/Patches/Patch_GenerateNingshaChild.cs`：拦截统一的 `GeneratePawn(PawnGenerationRequest)` 重载，在原版请求校验前准备参数，覆盖调试菜单和直接请求。
- `Race/Generation/NingshaChildGenerationUtility.cs`：只匹配 `DefOfRefs.NingshaRace_Child`。将默认成年限制调整为儿童；从 PawnKind 的3至17岁范围直接均匀抽样，作为本次请求的固定生物年龄，避免用全种族成年曲线反复尝试。
- 调用方提供包含年龄范围时先取交集；提供排除范围时按剩余左右区间长度抽样，空集直接抛出带请求信息的中文异常。
- 区间已参与抽样后清空请求区间，避免“固定年龄与区间同时存在”触发原版校验错误。
- 已指定固定年龄的请求不重新抽样；`NingshaReproductionUtility.HatchEgg` 仍生成生物年龄和实际年龄均为3岁的儿童，不影响父母关系、服装和蜕皮继承。
- 明确要求婴儿或新生儿的请求保持原样。成年凝砂、普通人和其他 PawnKind 完全不经过儿童年龄抽样，不改变全种族年龄曲线或18岁成年设定。
- 不接管原版人物创建、成长或实际年龄计算，不增加重试次数，不吞日志，不迁移已生成的错误人物。

## 验证范围

本轮只进行原版源码核对、Release 编译、XML 与文本静态检查，不启动 RimWorld、不运行生成测试。

以下均为交付后的待手工验收项：

1. 原版调试菜单“生成角色”选择“凝砂族儿童”，能够生成3至17岁儿童，不再输出300次年龄尝试错误。
2. 多次生成能覆盖低龄儿童、少年与青年，不只集中在14至17岁；使用各自生命阶段的绘制和儿童服装。
3. 孵化受精卵仍为固定3岁，父母关系、凝砂异种和母方蜕皮层数照常继承。
4. 生成成年凝砂殖民者、普通人和其他种类，原有年龄规则不受影响。
5. 集成调用方提供3至8岁包含范围或排除部分儿童年龄时，结果服从范围；完全无可用年龄时报告明确错误，不进入300次重试。

# 沙漠墓葬地牢摆放说明

## 文档目的

本文档用于指导关卡、美术或地图摆放人员制作凝砂族沙漠墓葬地牢模块。目标是让地牢既有地下陵墓的仪式感，又适合 RimWorld 的 2D 格子地图探索、战斗和随机生成。

摆放时优先保证少量模块可复用，不追求一次性覆盖所有房间类型。低预算版本只需要入口、前厅、走廊、小墓室、储藏房、主墓室和少量坍塌连接件，后续程序通过旋转、复用和局部装饰变化组合成不同地图。

## 整体风格

- 地牢主题是沙漠地下墓葬，视觉关键词为砂岩、风化、半埋、裂纹、墓室、图腾、陶罐、石棺、骨骸、细沙和塌方。
- 人工结构与天然洞穴混合存在。主墓道、前厅和主墓室偏规整，边缘支路、坍塌区和蛇巢偏自然。
- 重要区域可以更对称、更完整；普通支路和废弃区域应有破损、倾斜、半堵塞和沙埋痕迹。
- 奖励房不要过密堆资源，重点通过罐子、陪葬品、隐蔽入口和危险点制造探索欲。

## 推荐地牢拓扑

基础结构建议如下：

```text
坍塌入口
  ↓
献祭前厅
  ├─ 陶罐储藏室
  ├─ 侧墓室
  └─ 守卫甬道
        ↓
      主墓室
        └─ 隐藏宝库
```

预算允许时可以额外加入一条坍塌环路：

```text
侧墓室群 ── 沙封走廊 ── 主墓门厅
```

这条环路能让玩家产生绕路、探索和回收路线的感觉；如果预算不足，可以先不做。

## 房间模块清单

### 坍塌入口

作用职责：作为玩家进入地牢后的缓冲区域，建立沙漠地下墓葬的第一印象。

- 推荐尺寸：7x7 到 11x9。
- 推荐内容：碎石、软沙、半埋图腾、少量罐子、坠砂痕迹。
- 不建议放高价值奖励。
- 入口附近需要留出清晰通行空间，避免玩家刚进入就被建筑卡住。

### 献祭前厅

作用职责：作为第一个正式墓葬空间，并承担分流到支线房间的功能。

- 推荐尺寸：11x9 到 15x13。
- 推荐内容：对称石柱、破损祭台、图腾、少量骨骸、两侧门洞。
- 可以连接陶罐储藏室、侧墓室群和主墓道。
- 地面可以比入口更规整，表现人工修建痕迹。

### 守卫甬道

作用职责：连接前厅和主墓门厅，制造仪式感和轻度危险。

- 推荐宽度：普通 3 格，主走廊 5 格。
- 推荐长度：8 到 22 格。
- 推荐内容：两侧雕像、壁龛、罐子、骨堆、碎石。
- 可以设置少量伏击点、蛇罐或陷阱位置。
- 不要全程直线无遮挡，建议加入轻微转折或局部塌方。

### 陶罐储藏室

作用职责：作为玩家可互动的小奖励房，集中放置可击碎罐子。

- 推荐尺寸：7x7 到 11x9。
- 推荐内容：罐子、碎陶片、草药、少量资源、细沙。
- 罐子应成组但不要完全贴满，给 Pawn 留出移动和战斗空间。
- 可以放一个明显入口，也可以放在支路尽头。

### 陪葬品库

作用职责：作为中等奖励房，提供比陶罐储藏室更明确的探索收益。

- 推荐尺寸：7x7 到 12x10。
- 推荐内容：小箱、资源堆、雕像、玉石、金银、古代残骸。
- 可以使用堵门、破墙、塌方或绕路来限制直接进入。
- 奖励点需要与危险点保持一定距离，避免玩家刚进门就被完全围住。
- 低预算版本可以不单独制作，把奖励内容合并进主墓室或隐藏宝库。

### 防腐净身室

作用职责：表现墓葬仪式流程，提供非战斗叙事空间。

- 推荐尺寸：9x7 到 13x11。
- 推荐内容：石台、药草罐、干涸水槽、骨骸、破布、少量石棺。
- 这个房间可以奖励较少，重点是营造气氛。
- 可以放在主墓道旁边，也可以作为祭司墓室前置空间。
- 低预算版本可以不单独制作，把石台、药草罐和干涸水槽元素合并进献祭前厅。

### 侧墓室群

作用职责：形成地牢支线探索区域，并承载普通墓葬内容。

- 单个侧墓室推荐尺寸：6x6 到 9x8。
- 推荐内容：石棺、图腾、罐子、骨骸、沙堆。
- 低预算版本只需要 1 个可旋转复用的侧墓室模块。
- 多个侧墓室可以围绕一条短走廊展开。
- 每间侧墓室应有轻微差异，例如棺材数量、破损程度、罐子密度或是否坍塌。

### 祭司墓室

作用职责：作为侧墓室群中的重点房间，提供更强视觉中心和支线奖励。

- 推荐尺寸：9x9 到 13x11。
- 推荐内容：特殊图腾、较完整祭台、发光砂晶、少量陪葬品。
- 可以设置更窄入口或前置小门厅。
- 视觉上应明显高于普通侧墓室。
- 低预算版本可以不单独制作，把特殊图腾和发光砂晶放入主墓室。

### 蛇巢空腔

作用职责：作为危险房，制造沙漠墓葬中的生物风险。

- 推荐尺寸：7x7 到 12x10。
- 形状建议不规则，不要像标准房间。
- 推荐内容：破罐子、骨堆、草丛、软沙、眼镜蛇刷新点。
- 不建议放太多高价值奖励，避免变成必须清理的大型战斗房。
- 低预算版本可以不单独制作，用普通侧墓室替换部分装饰来表现危险房。

### 沙封走廊

作用职责：作为坍塌环路和自然洞穴过渡区域。

- 推荐宽度：2 到 5 格。
- 推荐内容：塌方岩、软沙、碎石、半埋墙体、裂缝。
- 可以局部堵塞，但需要留出可通行路径。
- 适合连接侧墓室群和主墓门厅。

### 主墓门厅

作用职责：作为主墓室前的仪式过渡区，提示玩家即将进入核心空间。

- 推荐尺寸：13x9 到 17x13。
- 推荐内容：对称图腾、成排雕像、门柱、发光晶体、破损封门。
- 这里应有明显的视觉轴线，指向主墓室入口。
- 可以设置少量守卫或危险罐子，但不要过度拥挤。
- 低预算版本可以不单独制作，把门厅功能合并到主墓室入口前 3 到 5 格。

### 主墓室

作用职责：作为地牢高潮区域，承载核心墓葬、主要奖励和最终风险。

- 推荐尺寸：17x15 到 25x21。
- 推荐内容：主棺、大祭台、核心图腾、陪葬品、守卫点、罐子、发光晶体。
- 布局应比其他房间更完整、更对称。
- 中央主体必须清晰，不要被小装饰遮住。
- 四周可以有小隔间、壁龛或半封闭陪葬区。

### 隐藏宝库

作用职责：作为可选高价值奖励房。

- 推荐尺寸：5x5 到 9x7。
- 推荐内容：金银、玉石、古代零部件、少量特殊装饰。
- 入口建议通过破墙、偏门、塌方背后或主墓室侧门进入。
- 宝库不需要大，关键是隐蔽和紧凑。

### 后出口或逃生裂隙

作用职责：减少玩家原路返回距离，并让地牢结构更自然。

- 推荐宽度：2 到 4 格。
- 推荐内容：天然洞壁、软沙、塌方、少量植物或水痕。
- 可以连接回入口附近，也可以作为地图另一侧出口。
- 不建议放太多奖励，主要服务路线体验。
- 低预算版本可以不做后出口，让玩家原路返回。

## 低预算模块交付数量

建议优先交付最小可用模块包。不要追求每类房间都有多个变体，先保证一张地牢能完整跑通。

| 模块类型 | 建议数量 |
| --- | --- |
| 入口模块 | 1 个 |
| 前厅模块 | 1 个 |
| 直走廊 | 1 个 |
| 转角走廊 | 1 个 |
| T 字路 | 1 个 |
| 小墓室模块 | 1 到 2 个 |
| 陶罐储藏室 | 1 个 |
| 主墓室模块 | 1 个 |
| 隐藏宝库 | 1 个 |
| 坍塌连接模块 | 1 到 2 个 |

最低成本可以只做 9 到 11 个模块。通过旋转、镜像思路、替换装饰和随机散布罐子，可以撑起第一版地牢。

## 摆放规则

- 每个房间至少保留一条 2 格以上的可通行路径。
- 重要通道推荐 3 格宽，主墓道推荐 5 格宽。
- 大型摆件不要堵住门口中心线。
- 罐子可以集中，但不要让 Pawn 无法近战接近或绕行。
- 石棺、图腾、祭台适合放在视觉轴线上；碎石、骨骸、罐子适合放在边角和墙边。
- 奖励点和危险点要分层，不要所有奖励都堆在主墓室。
- 支线房间要有价值，但不能比主墓室更像终点。
- 坍塌区域可以打破规整结构，但不能让地图主要路径断开。
- 每个模块都要考虑旋转后仍然成立，除非明确标记为固定朝向模块。

## 程序生成接口建议

如果后续要把这些模块接入程序生成，建议每个模块记录以下信息：

- 模块名称。
- 模块类型。
- 模块尺寸。
- 入口位置。
- 可旋转方向。
- 是否允许贴边生成。
- 是否包含奖励点。
- 是否包含危险点。
- 是否需要保持完整封闭。
- 是否适合主路，还是只适合支路。

示例：

```text
模块名：陶罐储藏室A
类型：储藏室
尺寸：9x7
入口：南侧中心 3 格
可旋转：是
奖励点：低
危险点：低
适用位置：支路尽头或前厅侧房
```

## 最小可用模块集

如果预算很低，第一版只需要完成：

- 1 个坍塌入口。
- 1 个献祭前厅。
- 3 个走廊连接件：直走廊、转角、T 字路。
- 1 个侧墓室。
- 1 个陶罐储藏室。
- 1 个主墓室。
- 1 个隐藏宝库。
- 1 个坍塌连接件。

这套一共 9 个模块，已经可以拼出一张有入口、支线、奖励和终点的沙漠墓葬地牢。蛇巢、祭司墓室、主墓门厅和后出口可以后续再补。

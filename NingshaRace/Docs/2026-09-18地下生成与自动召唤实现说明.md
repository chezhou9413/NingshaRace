# 地下生成与沙傀自动召唤

本次实现需求表第 98～101 项。第 102～104 项的两种巨伞菇及果实不在本次范围。

## 沙傀自动召唤

- 召唤沙傀图标右上角提供白色循环箭头，单独点击切换自动召唤；开启时图标底部显示蓝色光带，原有冷却槽继续显示。
- 每名召唤者独立保存开关。只有未征召的玩家凝砂族可以开启，征召后立即关闭。
- 开启时如果没有沙傀，会安排一次召唤。沙傀自然消散、死亡或被直接销毁时，会利用原有召唤者关联登记补召请求。
- 自动任务排在当前任务之后，不主动打断当前工作；同一角色不会重复排入同一能力的任务。
- 候选召唤地必须在本地图居住区内，符合角色允许活动范围、可达性和技能的沙地要求。执行任务时重新检查落点、开关、冷却及已有沙傀。
- 需要移动时先选择可达的施法站位，再执行原版能力施法与冷却流程，不直接调用生成器跳过施法。
- 居住区没有有效沙地时不能开启；开启后失去有效沙地会自动关闭，并发送右侧提示信件。临时被其他角色占用的沙地仍作为候选，空闲后再尝试安排任务。
- 主动收回不触发补召。手动替换或成功召唤后清理过时请求；关闭开关只撤销自动任务，不清理手动任务。
- 倒地、精神状态或未出现在地图上时暂停调度。开关和待处理请求随存档保存。

主要代码位于 `1.6/Source/NingshaRaceLib/SandGolem/Automation/`；专用图标命令位于 `SandGolem/UI/Command_SummonSandGolem.cs`。原有追踪器只增加生命周期通知，未改变沙傀贴图与绘制方式。

## 地下地图生成

以下调整作用于使用分层布局的普通巨坑和凝砂族地下开局地图，仅在新生成地图时生效，不改造已经生成的地图。

| 项目 | 当前实现 |
|---|---|
| 石林 | 每图 9～13 片，单片半径保持 7.5～11.5 格；生成前统一选择分散落点，中心至少间隔 15 格 |
| 河流 | 曲流幅度由 7 调至 12，曲流频率由 6 调至 10；继续保护出生干地、完整河岸和蚁巢占地 |
| 蚁巢附属洞室 | 每个蚁巢 1～3 个，半径 5～12 格，通过窄通道接入该蚁巢已有外部通路；核心巢室仍保留单入口 |
| 附属洞室额外连接 | 每个洞室独立以 50% 概率增加一条通往其他洞室的窄通道 |
| 沿河沼泽 | 每图 1～3 片，半径 4～10 格；采用不规则轮廓，实际区域约 80% 沼泽、20% 砂岩地面和沙地，比例按整数格取整 |
| 沼泽植物 | 在湿地中的干燥沙地斑块额外放置紫辉花簇菌，不允许所有植物直接长在水面上 |
| 生态洞室 | 主洞室和次要洞室周围全图共计 3～7 个，半径 5～10 格 |
| 坠砂裂隙 | 每个生态洞室有 50% 概率布置密集坠砂裂隙，目标每室 8～14 处，实际数量受可用干地与间距限制 |
| 中央水潭 | 仅在有坠砂裂隙的生态洞室中再以 50% 概率生成；申请半径 2～7 格，并按实际洞壁距离缩小以保留岸带 |
| 水潭岸带 | 铺设泥土，并生成号角树、棕榈树的耐阴地下变体；复用原版贴图，不生成仙人掌 |

洞室与湿地在布局阶段记录实际占地；地形步骤铺设水面和干地；植物步骤放置对应生态内容。生态区域保留在既有场景避让集合中，石林、碎石及其他散布内容不能覆盖这些区域。通行核心不放置石柱、树木与裂隙。

地图尺寸或配置造成必要结构无法放置时，生成器会明确报告位置或数量不足，不静默把目标数量减为零。随机地图的实际视觉效果与空间容量尚未进行游戏内验证。

## 可调整参数

参数集中在 `1.6/Defs/DesertPit/MapGeneration/Maps/NingshaRace_LayeredLayout.xml`：

- `stoneForestCount`、`stoneForestRadius`：石林片数与单片半径。
- `riverMeander`、`riverMeanderFrequency`：河流偏移幅度与弯曲频率。
- `antSideRoomCount`、`antSideRoomRadius`、`extraTunnelChance`：蚁巢外围洞室与额外通道。
- `marshCount`、`marshRadius`、`marshCoverage`：沿河湿地数量、半径和沼泽面积比例。
- `habitatRoomCount`、`habitatRoomRadius`：全图生态洞室数量与半径。
- `habitatSandfallChance`、`habitatPondChance`、`habitatPondRadius`：坠砂、水潭的条件概率与水潭半径。

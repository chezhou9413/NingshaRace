# 斜向河谷洞群实现与验收

## 参考图的落地方式

参考图中的白色方框视为洞室分布示意，不生成矩形房间。普通沙漠巨坑及凝砂开局采用同一套斜向河谷布局：中央大洞室及不等距侧室 → 两岸交错小洞群 → 两处次要洞室 → 延伸到外层的河谷洞群，并有偏离河道的探索支洞。蚁巢位于河谷两侧的中层，保留曲折单入口，不搬回地图角落。

普通巨坑继续为 200×200，凝砂开局沿用所选地图尺寸。祭坛任务地图和巨型墓葬不使用这套布局。旧地图不重塑，必须生成新地图才能看到轮廓变化。

## 算法与职责

- `Generation/Hydrology/DesertPitRiverPlanner.cs`：在蚁巢选址前确定斜向河道，主轴单调、横向平缓摆动，两端向对角方向展开。中央河弯绕过十二格出生干地；按真实河心提前记录水面和岸线。河流不再复用蚁巢最短路求解器。
- `AntColony/Generation/Chambers/AntChamberPlanner.cs`：完整岩层避开预留水系及一格相邻缓冲，防止洞口紧贴预留岸线而无法接通。根据河谷法向分居两侧，仍约束在中层。
- `Generation/Topology/DesertPitCaveProfile.cs`：一次采样洞室形状，以坐标扰动、不等大的偏心凸湾及多尺度边界变化形成不对称洞壁。同一洞室的选址候选复用形状，避免反复重抽轮廓。
- `DesertPitRoomBrush.cs`：裁去孤立边缘地面，以平滑弯曲、宽窄变化的洞口连通洞群。连接线遇到蚁巢时才执行避障寻路；不改变蚁巢厚壁及遮挡岩脊。
- `DesertPitRoomPlacement.cs`：最多三十二个黄金角局部候选，核对实际面积、中心净空及未开挖面积比例。洞室不能大部分叠在已有空地里，避免主次层级糊成整片。
- `DesertPitSecondaryRooms.cs`：按实际同心方形层位在河流上取点，左右岸交错安排连接洞室，保留两处必要次要洞室。
- `DesertPitValleyExtensions.cs`：每端继续放置外围洞室和离开河谷的支洞。支洞宿主使用固定列表，不递归扩张。

中央主洞仍保持开阔空间；洞壁形变不侵入出生净空。中央侧室向外错开，连接洞室也不再全挤在中央和次洞之间的很短距离内。

可选连接洞室、外围洞室或支洞放不下时减少数量，并在两端规划结束后汇总一条警告。中央洞、两处次洞、两座蚁巢、河流端点与连通性仍是必要条件，缺失时明确报错，不静默交付残缺主结构。

## XML 参数

入口：`1.6/Defs/DesertPit/MapGeneration/Maps/NingshaRace_LayeredLayout.xml`。不增加设置面板。

| 字段 | 默认值 | 作用 |
| --- | --- | --- |
| `centralRoomCount` | 6～8 | 中央洞群周围侧室数 |
| `smallRoomRadius` | 9～14 | 侧室、连接洞室和支洞半径 |
| `linkRoomCount` | 3～5 | 每端次洞与中央之间的连接洞室目标数 |
| `outerRoomCount` | 3～5 | 每端河谷向外层延伸的洞室目标数 |
| `outerRoomRadius` | 10～16 | 外围洞室半径 |
| `branchRoomCount` | 2～3 | 每端偏离河谷的支洞目标数 |
| `riverDiagonalReach` | 0.82 | 河流两端向横向地图边缘展开的比例，允许 0.5～0.9 |
| `riverMeander` | 7 | 河道曲流幅度，允许 2～12 格 |

尺寸沿用短边相对二百格的缩放，倍率限制 0.75～1.5；出生干地与河岸最低宽度不缩小。主洞半径 34～40 / 28～34、次洞半径 18～24、河宽 3～5、河岸宽 2、出生干地半径 12，以及菌巢稀疏配置保持不变。

新增外围洞室和支洞不额外生成共生菌巢：仍是原有三处保底菌巢，加两处次洞各自 0～3 处。基因、工蚁采收、死亡掉落、吐酸蚁和蚁狮行为不随本轮洞群调整改变。

## 验证边界与人工验收

只执行 Release 编译、XML 解析和文本差异检查，不启动游戏、不运行地图模拟、批量种子或压力测试。沿河规划及地图掩码写入保持串行；水道不再需要两次全图加权搜索，但洞室数量与轮廓采样增加，未测量实际生成耗时，不宣称整体必然更快。

游戏内待确认：

1. 新普通巨坑和新凝砂开局都有斜向贯穿的连续浅河，而不是两条笔直窄通道；河谷外围可见成组洞室。
2. 中央开阔、侧室错落，次洞小于主洞；洞壁有明显凹凸而非规则椭圆或矩形，洞室之间有自然收窄处。
3. 出生点、三名成员、物资、离洞绳均在干地，可正常移动和返回地表。
4. 两座蚁巢中心留在中层，厚壁没有被河流或支洞打穿，仍只有曲折入口。
5. 沿河洞群与外侧支洞可从主洞抵达；场景和植物生成后不堵河岸，菌巢仍保持稀疏。
6. 若有缺少可选洞室的警告，记录地图尺寸和种子；若出现红错，保留第一条完整堆栈。不要用旧地图判断本轮布局效果。

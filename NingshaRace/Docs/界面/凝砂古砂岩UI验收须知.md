# 凝砂古砂岩 UI 验收须知

本文件记录交付后的人工验收入口，全部运行时项目均为待手工。本次只编译与静态核对，不启动游戏。

## 共同检查

- 普通 UI 缩放和较大 UI 缩放下，中文标题、长人物名、长物品名不截断字形。超宽标题有省略或完整悬停提示。
- 所有窗口以原有静态砂岩质感为主：砂岩棕底色、细沙凹凸、边缘积沙清楚可见，旧铜边和角部刻印保持固定；不能被浅黄色或暗金色的浓厚风沙幕覆盖。
- 观察面板中央能看到轻微、连续流动的薄沙，不限于上下边缘；噪声仍有翻卷、破碎与重新聚拢，但只是底纹上的细微变化。沙尘最浓时也不遮掉原来的静态质感，不是固定轨道亮点或每帧完全不同的闪烁噪声。
- 细沙应比大颗粒多且柔和，不能看出等距行列、棋盘格或整齐同向的短划线；局部可自然稀疏或聚集，大小与形状有差异。粗细沙粒有速度差，受沙尘浓度影响平滑出现与消散。拉大窗口后颗粒不拉长，跨512像素宽高的面板不出现明显拼接线；拖动时背景跟随面板。
- 180×75状态面板、80×75技能按钮和小按钮的整个背景同样流动，不悬停时也可见。凹入输入框、禁用底板浓度较低，禁用原因仍清晰；悬停平滑增强，移开后恢复常驻强度。
- 暂停及不同游戏倍速下流速一致。标题、正文、技能图标和进度数值固定绘制在风沙之后，不位移、不被前景沙尘遮住；明暗沙尘掠过时文字仍清晰，进度值继续使用真实数据。
- 薄沙经过时，中文标题与说明段落通过细窄暗影保持清晰；阴影不越过原文字区域，不额外占一行，不改变省略、换行、点击或滚动行为。检查较大 UI 缩放下无字形边缘裁切。
- 流沙资源使用包含 `WeatheredSandstone` 和 `DriftingSand` 的 UI 包，同时更新 DLL 与包文件；不能用只有底材 Shader 的旧包。加载日志应能注册两项 Shader，缺失时保留首份完整错误。
- 替换资源后完整重启游戏再观察；运行中的材质和 Shader 已加载在内存中，仅覆盖磁盘文件不能证明当前画面使用了新参数。年龄问题的修复也需要加载本轮 DLL。
- 多个窗口和状态卡同时显示时，无连续亮带或整屏闪烁；滚动区中的面板被裁去时，风沙也必须随原版 GUI 裁剪，不能画到页签、页脚或面板外的游戏地图上。窗口最小尺寸、较宽窗口及 UI 缩放下都需检查平铺和可读性。
- 点击与悬停有清晰反馈；选中或开启状态为绿松石刻印；禁用说明可读。
- 暂停时悬停动画仍工作；进度高光不会越过真实填充比例。
- 进度条有柔和的明暗变化和细小颗粒，没有原来的硬竖线扫光；0%、接近 0%、50%、接近 100% 和 100% 时不越界，数字清晰，绿色标记两端可见。
- 玩家说明使用“点击查看详情”“关闭”“请选择要进行的操作”等直接表达；生成过程中不显示模板、模块、组件、线程和搜索尝试编号。开发日志仍保留完整定位信息。
- 打开再关闭凝砂界面后，原版按钮和文字的字体、颜色、对齐与输入启用状态不被污染。
- 切换存档后无残留窗口状态、重复资源增长或材质丢失；不要求旧存档业务数据迁移。

## 状态与命令

1. 同时选中凝砂族和沙傀，检查侵蚀、蜕皮、寿命三种石板；点击展开完整说明，关闭不会修改任何数值。
2. 检查低侵蚀、50%、75%、转化中颜色；蜕皮营养 59/60/100、20 层时刻度与业务按钮禁用原因一致。
3. 检查沙傀汇聚、稳定、自然到期及手动收回，寿命显示继续使用真实 tick，消散时不出现无效卡片。
4. 行动符印用鼠标及原有快捷键各执行一次；开关用多选分组切换，状态刻印与实际值一致。
5. 检查六个凝砂能力的可用、禁用、冷却、施法中、队列修饰键、多选、缩小命令模式；冷却结束后不得继续显示锁定状态。
6. 原版建筑命令、其他种族能力和混合右键菜单不应被全局换肤。
7. 普通命令为 80×75，图标位于名称上方并明显大于旧版；技能顶部没有整行空白。名称过长时省略并保留完整提示，不画到边框外。蜕皮图案的细边没有被裁去。
8. 冷却中平时只显示细条；悬停时可读到准确剩余时间，大字体放不下额外时间标签时使用完整提示。快捷键、能力次数和开关标记不互相盖住。

## 货运

1. 分别打开向地表与向地下的货运窗口，切换动物/物资页签；搜索不能清除其他页签已选数量。
2. 输入 0、1、最大库存，使用加减、全部与清空；总数与实际清单一致，不包含殖民者。
3. 输入负数、非整数、超出库存数值及空值：输入有警告，确认与确认键不得提交旧数量。
4. 重置恢复零选择；取消不派发；确认只生成一份货运任务，保留原同类物资分组规则。
5. 大列表滚动时，条目不画到页签、标题或页脚上；窄窗口使用双排行而非控件互相覆盖。

## 其他窗口

- 摆放目录：用中文、DefName、分类搜索；展开/折叠分类；选择条目后仍使用原地图点击/拖拽摆放，右键退出。
- 生成进度：打开/收起说明不会中断生成；关闭键、取消键和保存仍被原业务规则阻止；真实生成结束后窗口关闭。
- 祭坛拒绝：普通与开发者模式下按钮不盖住接受、即时接受或任务倒计时；确认不退款，取消不释放任务槽。
- 侵蚀过载：会达到上限时出现完整不可逆警告；确认回调只执行一次，取消无数值变化。
- 独立指引选择：三项选择保留原生成回调；游戏已有任务时仍按业务规则拒绝，不因界面不同绕过限制。

发现问题时记录窗口名、UI 缩放、屏幕分辨率、完整首条日志和截图。Shader 丢失需同时检查 UI 包、CL 声明和游戏加载列表，不能用屏蔽日志替代修复。

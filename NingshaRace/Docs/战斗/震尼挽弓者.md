# 震尼挽弓者

目标为 RimWorld 1.7。开发者菜单选择 `NingshaRace → 生成震尼挽弓者（敌对异常）`。单位不会加入随机遭遇，倒地收容、研究、逃脱和死亡消散沿用震尼系列；不进行近战追敌瞬移。

## 射击表现

- 普通幽箭沿用大弓参数：射程 29.9、蓄力 2 秒、冷却 1.5 秒、单发伤害 17、穿甲 0.15、弹速参数 49。
- 每三次成功发射普通箭，下一次发射凝焰爆裂箭；失败或中断不推进计数，计数随单位保存。强化蓄力倍率 1.75（基础 3.5 秒，仍受原版瞄准属性影响）。放箭前 0.65 秒出现拥刀者同款星芒，持续 0.36 秒。
- 强化箭体放大至 1.25 倍，配合三股偏蓝紫螺旋；命中或护盾拦截时按原版即时爆炸流程，在半径 2 格内结算一次 17 点 Bomb 伤害、穿甲 0.15，不再叠加普通箭的直击伤害。爆炸受原版墙体阻隔，不点燃地面；只有该强化箭具有范围伤害。
- 强化爆焰使用独立的体积积分分支：短亮芯、五瓣翻卷焰团、受前层遮挡的地面扩散环与细小灰烬。默认视觉半径 2.1 格、时长 0.95 秒、亮度 1、辉光 0.3，局部明暗和冷色焰纹表现厚度。
- 待机显示原版，蓄力期间保持差分 1 的拉弦姿态；成功射出后依次播放差分 2（默认 0.12 秒）、差分 3（默认 0.20 秒），随后回到原版。上下弓臂同步切换，火焰持续流动；取消蓄力或发射失败不播放后两帧。箭矢在蓄力时显示于弓口，发射后移除。
- 躯体、斗篷内焰、局部火苗和上下弓臂持续飘散灰烬；尺寸按拥刀者对应火屑和画布比例换算，箭矢灰烬沿用刀身火屑的实际尺寸及长宽比例。四帧弓臂共用两组灰烬发射器，换帧时保留粒子。
- 普通箭明显燃烧，并沿实际飞行路径脱落灰烬。命中或原版进入护盾命中流程时出现柔软亮芯、翻卷焰团和薄雾，默认爆焰半径 0.8 格、时长 0.55 秒、亮度 0.85、辉光 0.3，余烬随弹丸销毁后继续淡出。普通箭的火焰为视觉效果，不附加爆炸伤害、点燃、灼烧或地面火，碰撞与伤害仍由原版弹丸处理。
- 双股尾迹使用挽弓者专属紫焰 Shader，连续亮芯包裹半透明焰带和柔光，亮部进入 RimUnity HDR 泛光。默认半径 0.18 格、螺距 1.2 格、亮带宽度 0.1 格、最大长度 4 格、寿命 0.3 秒、每秒旋转 1.5 圈。拖尾衔接点为箭尾实心火焰的 UV `(0.82, 0.52)`，随图层变换；按与箭体相同的 RG 波动和破碎场反求可见位置，以八段曲线向箭体内延伸 0.3 格渐融。普通双股与强化三股在合拢处分摊亮度，避免重叠成白色硬接头。连续网格共用接缝顶点，最旧端按实际保留长度在 0.4 格内渐细淡出，采样容量裁切也不会直接留下亮色截面。
- 放箭位置是视觉参数：箭体从握持点接向原版命中终点，不通过移动逻辑发射起点越过障碍。

## 可视化编辑

选中可站立的挽弓者，在开发者模式下打开两个独立入口：

1. **外观编辑器**：四向身体、内外斗篷、背匣、眼光、火苗、火星，以及握把和八个弓臂图层。选中某一弓臂时显示该套差分，可以拖动部件和火焰根部、方向手柄。
2. **射击特效编辑器**：时间轴、播放／暂停、单步、循环、预览速度、四向切换和滚轮缩放。可切换普通箭与强化箭预览；参数分为拉弓、箭头、箭尾、螺旋、灰烬、强化六页。强化页设置蓄力倍率、星芒提前量、持续时间、大小和亮度，以及强化箭体、三股螺旋、爆焰和余烬参数。视觉半径不改变半径 2 格的战斗范围。时间轴支持查看命中后的完整消散过程。

拉弓页分别设置待机、拉弦、发射首帧、发射末帧的贴图编号，以及两张发射帧的时长。XML 中 `frame0`～`frame3` 对应这四种用途，`releaseSeconds` 和 `recoverySeconds` 对应两张发射帧；拉弦时长跟随实际武器预热，不再划分蓄力换帧比例。

预览暂停地图，只绘制模拟箭矢，不发射真实弹丸。参数调整仅修改当前草稿；关闭窗口恢复 Def 默认值。未导出的修改会提示确认。导入失败保留原草稿，红框输入不能导出。

射击预设保存到游戏存档目录下的 `NingshaRace/BowbearerPresets`，界面可复制目录；外观预设沿用现有外观编辑器目录。导出的 XML 可分别替换本单位的 `BowbearerShooting.xml` 和 `BowbearerAppearance.xml`，重新加载游戏后成为默认参数。预设检查 Def 名称，不能混入拥刀者或持斧者配置。

## 素材与源码位置

原稿为 `D:/QQ/弓兵测试(三视图).psd`。已导出的四向 1024² 贴图、握把、四套双段弓臂、独立箭头箭尾和持弓图鉴保留在 `1.7/Textures`，来源坐标记录位于 `SourceAssets/Zhenni/Bowbearer/分层朝向坐标.json`。

素材导出、离线特效预览和专用 Shader 发布脚本已移除。游戏内的外观与射击特效编辑器、XML 导入导出仍按上文使用。

源码按 `1.7/Source/NingshaRaceLib/Zhenni/Bowbearer` 下的 Defs、Combat、Rendering、Editor 分类。C# 编译沿用 `Tools/Build/Build-1.7.ps1`。Shader 源码位于 `SourceAssets/Effects/Zhenni/Bowbearer/BowbearerGhost.shader`，游戏使用 `1.7/Data/RimUnity` 中已有的资源与清单。

历史离线渲染产物位于仓库外的 `E:/ModdevMics/Outputs/NingshaRace`；其中的近似泛光不代替游戏内碰撞、护盾和多单位验收。

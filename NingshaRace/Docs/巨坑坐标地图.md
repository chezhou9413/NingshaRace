# 巨坑坐标地图

## 玩家流程

符合投放条件的来访商队携带一张巨坑坐标地图，基础价值500银、重量0.1、不可堆叠。选择物品并指定成员解读，或通过成员右键菜单解读，持续120刻后自动开启“寻找巨坑”。成功创建任务后消耗物品。

坐标以使用者所在地图为准，保存该地图的完整尺寸。任务无期限，远行队进入目标地表即完成；通过地表巨坑入口继续探索原有200×200地下地图。地表、地点和已经生成的地下地图永久保留，可重访、取回物资，并从地表重新组建远行队。

同一时间只允许一个寻找任务。完成并离开巨坑后，可以再次获取地图寻找新的地点。

## 坐标规则

- 距离采用星球地表相邻地块的最短步数，不采用远行队绕行路线长度。
- 找距离使用地点超过20格的最近普通沙漠，并列按地块编号选择。
- 从该沙漠五格范围内随机选择地点，包括中心地块；最终位置必须仍为普通沙漠、距离使用地点超过20格、可由远行队抵达且没有世界对象占用。
- 不包含极端沙漠。没有合法候选时提示原因，保留物品，不创建地点或任务。

## 商队投放

在非敌对来访贸易群组创建完成时检查一次，不在打开交易界面时补货。全玩家范围无地图、没有进行中任务、没有玩家成员位于巨坑地下或任务地表时，向载货成员加入一张地图。没有驮兽时放入商人背包，并通过货物枚举补丁使其可交易。

持有检查覆盖殖民地可见地面物品、仓储物品、玩家容器、成员背包、远行队和运输中的玩家物品；不把来访商队背包当作玩家持有。已经携带地图的商队不会重复添加，也不会因玩家后续状态变化移除现有地图。

## 维护入口

- 代码：`1.6/Source/NingshaRaceLib/DesertPit/Discovery`，分为定义、物品、任务、世界地点和贸易模块。
- 定义：`1.6/Defs/DesertPit/Discovery`。
- 贴图：`1.6/Textures/Things/Item/NingshaRace/DesertPit/CoordinateMap.png`。
- 生成源图：`SourceAssets/DesertPit/Discovery/CoordinateMap.generated.png`，使用imagegen生成并保留透明通道。

世界地点保存地图尺寸、任务关联、入口引用和发现状态；远行队动作保存目标地点引用。没有旧存档迁移逻辑。

## 验证范围

只执行静态引用检查和Release编译，不启动游戏。游戏内交互、地图实际生成及存读档往返没有运行验证。程序集输出使用项目既有的`1.6/Assemblies`目录。

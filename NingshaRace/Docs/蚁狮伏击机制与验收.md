# 蚁狮伏击机制与验收

## 交付范围

实现蚁狮三向贴图导入、独立敌对派系、地下伏击、短时加速、有限追击、寻找沙地与存档恢复。只在新生成的普通沙漠巨坑和凝砂族开局巨坑放置，不修改地表生态、祭坛任务或旧地图。

蚁狮初版及吐酸蚁朝向、绿色拖尾已于 2026-09-07 部署到 Steam 本地模组目录。当前沙尘可见度调整只完成 Release 编译和代码、XML 静态检查，尚未再次部署；不启动游戏、不进行地图模拟、性能基准或战斗测试，不提交或推送。编译通过不代表动画观感与实战强度已经验收。

## 行为契约

| 阶段 | 行为与退出条件 |
| --- | --- |
| 地下潜伏 | 地图上只有不可选中、不可攻击的持有容器；原 Pawn 被挂起。间断播放浅沙色细粒，3 格内出现可见可达的人类或动物时出土。 |
| 出土 | 18 tick 的身体展开与扬沙；可受伤，但不在动画完成前攻击。优先原格，被占用时只考虑可直达的相邻空格，不挤走 Pawn。 |
| 追击 | 使用原版近战驱动的派生任务；前 180 tick 移速乘 1.7，之后恢复。目标、蚁狮位置和下一步均受出土点 12 格边界限制。 |
| 寻找沙地 | 放弃当前猎物后搜索当前位置 12 格内最近的合法沙地并步行到达；无可用位置则留在地表，每 120 tick 重试。 |
| 下潜 | 30 tick 的身体收拢与扬沙，完成前仍可受伤、可被附近合格猎物中断；完成后把同一 Pawn 转回容器，120 tick 后重新启用伏击。 |

- 猎物包括殖民者、其他人类、动物及原有蚁群；排除机械体、其他蚁狮、死亡、倒地和不在同一地图上的 Pawn。
- 感知采用圆形距离，需要视线和不穿越关闭门、水域的可达性；不隔墙触发，不攻击建筑或破门。
- 猎物死亡、倒地、离图、超过边界或连续 120 tick 不可达时，终止攻击。仅尝试接替身边 3 格内、仍在原追击边界内的另一只猎物，不刷新加速。
- 本次出土中不立即重新选择刚放弃的猎物，避免路径持续受阻时在追击和返回间反复切换。
- 回程遇敌仍遵守原出土点的追击边界；下潜期间重新遇敌只恢复追击，不重复赠送出土加速。
- 下潜要求地表为允许的沙地，格子没有建筑、植物、掉落物、其他 Pawn 或其他潜伏容器。目标格被占用或寻路失败后延迟重试，不瞬移。
- 铺地或实体覆盖已有潜伏格时，尝试将原蚁狮安全释放到原格或相邻直达空格。没有安全空格就保留持有状态等待空间恢复，不拆墙、不破坏玩家物品。
- 蚁狮倒地或着火时不能下潜；自身死亡保留正常尸体，不复活、不生成替身。干枯尸体复用原画轮廓和原版虫类尸体着色。
- 暂不加入饥饿、繁殖、驯服或特殊掉落；尸体沿用原版虫肉。潜伏不回血、不重置伤势，地下期间挂起健康更新。

## XML 配置入口

行为与战斗：`1.6/Defs/DesertPit/Antlion/NingshaRace_Antlion.xml`。

| 字段 | 默认值 | 含义 |
| --- | --- | --- |
| `triggerRadius` / `chaseRadius` | 3 / 12 | 感知半径 / 从出土点计算的追击半径 |
| `burstMultiplier` / `burstTicks` | 1.7 / 180 | 出土动画结束后的移速倍率和持续时间 |
| `emergeTicks` / `submergeTicks` | 18 / 30 | 出土和下潜动画时长，动画自动适配 |
| `sandSearchRadius` | 12 | 从当前地表位置搜索沙地的半径 |
| `scanIntervalTicks` | 10 | 地表和地下目标检查间隔，按实体编号错峰 |
| `unreachableTicks` | 120 | 持续无法到达猎物的放弃时限 |
| `sandRetryTicks` / `rearmTicks` | 120 / 120 | 搜索沙地重试间隔 / 潜伏后重新触发间隔 |
| `burrowTerrains` | Sand、SoftSand | 允许潜伏的实际地表，不包含其上铺设的地板 |

所有时间单位为 tick，60 tick 约为正常速度下的一秒。半径必须为正数，局部搜索半径必须小于原版径向格子表上限；追击半径不得小于感知半径，时间和检查间隔必须大于零，错误配置直接输出定义错误。

基础移速 3.4，生命倍率 1.6，体型 1.2，咬击伤害 12、冷却 1.8 秒，锐器护甲 18%、钝器护甲 10%，战斗力 120。移速的最终值仍受原版伤势、地形和其他合法属性影响。

自然生成：`1.6/Defs/DesertPit/Biomes/NingshaRace_DesertPitBiome.xml` 中的 `DefModExtension_DesertPitAntlion`。

- `countRange=2~3`：每个新巨坑的数量；设为 `0~0` 可关闭自然生成。
- `entranceAvoidRadius=25`：避开主洞中心和实际出口。
- `antNestAvoidRadius=24`：避开两座蚁巢中心。
- `spacing=18`：蚁狮之间的最小距离，同时排除保护通道和保留场景。
- `scanBatchSize=512`：一次生成迭代扫描格数。候选只扫描一次，数量不足时减少生成并输出一次警告。
- 自然生成步骤顺序为 465，位于植物和其他实体之后；两个巨坑生成器各登记一次，不向其他地图注入。

沙尘配置入口：`1.6/Defs/DesertPit/Antlion/Effects/NingshaRace_AntlionSand.xml`。颜色和寿命位于三个 FleckDef 中，密度与尺寸位于沙尘定义的 `DefModExtension_AntlionSandEffects` 中，不需要打开设置面板。

| 视觉配置 | 默认值 | 表现 |
| --- | --- | --- |
| `buriedIntervalTicks` / `buriedGrains` | 16 / 12 | 每次发射明暗混合沙粒和两团小沙尘，不随机跳过整次提示 |
| `buriedRadius` | 0.55 格 | 偏心、局部的沙地扰动，不绘制规则圆环 |
| `buriedGrainScale` | 0.085～0.15 格 | 配合随机拉伸和转动，避免普通缩放下完全看不见 |
| `buriedDustScale` | 0.55～0.80 格 | 椭圆形沙尘托住细粒，保持局部范围 |
| `transitionIntervalTicks` / `transitionGrains` | 5 / 14 | 出土向外喷散，下潜向中心收拢，并保留少量侧向漂移 |
| `eruptionGrains` | 36 | 出土起始瞬间的一次喷沙，另有五团快速散开的沙尘 |
| `movingGrainScale` / `movingDustScale` | 0.10～0.20 / 0.85～1.20 格 | 出入沙地阶段的尺寸，不影响身体动画时间 |

潜伏沙尘约 0.69 秒淡出，出入沙地沙尘约 0.56 秒淡出，沙粒约 0.61 秒淡出。沙尘使用原版 `DustPuff` 纹理和普通非发光材质；沙粒约 38% 为少量褐色细沙，其余为浅沙色，在浅色地面上形成局部对比，不用深色烟幕提高可见度。全部特效仅在已揭雾、镜头附近的非阻挡格创建，接触墙壁后停止传播。

潜伏发射间隔至少 8 tick，切换阶段间隔至少 3 tick，单次沙粒配置限制在 0～64，潜伏半径不超过 1.5 格，各尺寸上限为 2 格。无效配置输出定义错误；默认值不改变任何感知、追击、伤害、加速或出入沙地时长。调整视觉 XML 后需要重新加载模组，但已有蚁狮无需重新生成。

## 技术入口与所有权

源码统一位于 `1.6/Source/NingshaRaceLib/DesertPit/Antlion`，按 `AI/Jobs`、`Components`、`Holders`、`State`、`Generation`、`Effects`、`Rendering` 拆分。

- `CompAntlionAmbush`：保存阶段、猎物、放弃目标、出土点、沙地目标、不可达起点、阶段起始时间和加速期限；追击与下潜分别放在部分文件中。
- `AntlionBurrow`：`ThingWithComps + ThingOwner<Pawn>`，实现持有、禁止内容更新和挂起接口。地下只有容器深度保存 Pawn，地表只有地图保存 Pawn；出土后销毁的是空容器。
- 删除容器或卸载地图时清理持有链、必要的原版世界登记和 Pawn，不生成尸体或第二只生物。正常地表死亡完全交给原版处理。
- `JobDriver_AntlionAttack`：继承原版近战任务，增加目标与边界终止条件。`JobDriver_AntlionWait` 不使用原版等待自动攻击，避免误打机械体；沙地任务实际步行，不使用传送。
- `StatPart_AntlionAmbushSpeed`：条件 XML 补丁追加到原版移速属性，仅匹配蚁狮；不覆盖蜕皮或其他模组的属性项。阶段变化和到期清理该 Pawn 的属性缓存。
- `AnimationWorker_AntlionBurrow`：使用原版动物渲染树和动画节点，读取已保存阶段进度，不引入 Shader、材质资源或全局渲染补丁。
- 状态修改与持有物转移串行完成；局部搜索不创建后台任务。所有沙尘随机数以独立状态包围，包含粒子创建内部使用的随机数。
- `checkOverrideOnExpire` 仅赋值给运行中的 `Job`，不作为 `JobDef` XML 字段。

原始贴图保留于 `生物/蚁狮`；运行时目录为 `1.6/Textures/Things/Pawn/Animal/NingshaRace/DesertPit/Antlion`。正面对应 `_south`，背面对应 `_north`，左向侧图对应 `_west`。渲染树对东西两个身体网格校正镜像，不修改原图片。三个导入文件与原文件 SHA256 一致。

## 游戏内人工验收清单

以下用例尚未运行；本次交付不启动游戏执行。

1. 新开凝砂族开局并另外生成普通巨坑：两种地图都有 2～3 个地下蚁狮；入口、开局区、主通道和蚁巢附近没有贴身伏击点。地表与祭坛任务不生成。
2. 在普通缩放、较远缩放和浅色沙地检查潜伏处：应能看到约一格范围内的明暗细沙流动，而不是只在极近镜头才看得见。提示不能选中或被自动瞄准；离开镜头、未揭雾时无粒子泄露位置，暂停时动画停住。
3. 让殖民者、其他人类、动物和蚁群分别进入 3 格内；圆形边界外不触发，墙壁和关闭门后不触发。机械体、其他蚁狮和倒地生物不触发。
4. 出土约 0.3 秒后开始追击，前约 3 秒移速增加 70%，之后恢复；追击超过最初 3 格仍继续，超过出土点 12 格则停止，不绕边界持续追赶或破门。
5. 分别制造猎物死亡、倒地、离图和关门断路，确认停止追击、不补刀；另有近处合格目标时可接替，但不会刷新加速或全图搜敌。
6. 检查蚁狮真实步行到最近可用沙地，下潜约 0.5 秒后隐藏；附近没有沙地时保持地表，不瞬移、不循环报错。移动到目标格上的其他 Pawn 能使其重新选址。
7. 下潜中进入新的合格猎物可打断；蚁狮倒地、着火或死亡时不能完成下潜。自身死亡只有一具正常尸体，腐烂与干枯阶段不缺图。
8. 分别在地下、出土、爆发追击、爆发结束、寻找沙地和下潜阶段存读档，确认 Pawn 身份和伤势不变，不重复生成，不重新获得完整加速，动画从保存进度继续。
9. 修改沙地为地板、占用原格，以及删除潜伏容器或卸载地图，确认不覆盖玩家建筑、不出现孤立 Pawn、重复尸体或循环错误。
10. 检查四向朝向、受伤图层和动画缩放；出土瞬间应有明显向外喷散的短促扬沙，下潜时应看到向中心卷入的沙粒，半秒左右逐步淡出且不长期遮住人物。用三名基础装备殖民者实际作战确认中等威胁定位，记录伤亡与粒子观感后再决定数值微调。
11. 修改 XML 数量、距离、加速和动画时长后重启游戏，在新地图确认生效；用 `0~0` 验证关闭自然生成，不要求旧地图已有蚁狮消失。

发现红字时保留第一份完整堆栈，以及地图种子、模组列表、蚁狮当前阶段和最近操作。不得用吞异常、屏蔽日志或启动时强制替换旧存档掩盖问题。

# 吐酸蚁纹理接入说明

## 当前范围

用户提供的三张透明 PNG 已接入吐酸蚁种族、生成种类和战斗逻辑。保留原始1024×1024尺寸、颜色和透明通道，不裁切、不缩放、不重绘。三级及以上的等级蚁巢会生成并补充吐酸蚁。

## 路径与朝向

文件位于 `1.6/Textures/Things/Pawn/Animal/NingshaRace/DesertPit/AntColony/AcidAnt`。

| 用户文件 | 项目文件 | 朝向 |
| --- | --- | --- |
| `D:/QQ/酸蚁 正.png` | `AcidAnt_south.png` | 南，正面 |
| `D:/QQ/酸蚁 侧.png` | `AcidAnt_west.png` | 西，头朝左 |
| `D:/QQ/酸蚁 背.png` | `AcidAnt_north.png` | 北，背面 |

图形基础路径为 `Things/Pawn/Animal/NingshaRace/DesertPit/AntColony/AcidAnt/AcidAnt`，不带朝向后缀和扩展名。

原版 `Graphic_Multi.Init` 支持只有西向侧图的情况：缺少东向图时复用西向图并设置东向镜像。已配置 `GraphicData.allowFlip=true`，不要把头朝左的原图误命名为 `_east`，也不必保存内容相同的第二张侧图。

## 核对与配置入口

- 三张项目文件与对应用户源文件的 SHA-256 一致，原文件未改动。
- 三张图均带透明背景，四角透明度为0。
- 绘制尺寸配置为1.9，未调整其他蚂蚁的尺寸；各朝向的游戏内视觉效果待人工验收。
- 定义文件：`1.6/Defs/DesertPit/AntColony/AcidAnt/NingshaRace_AcidAnt.xml`。
- 喷酸弹丸暂借用现有飞针贴图并染绿，正式弹丸美术可替换 `NingshaRace_AcidCombat.xml` 的 `texPath`。
- 本轮包含代码和 Def 变更，需使用配套 Release DLL；未启动游戏、未部署、未提交推送。

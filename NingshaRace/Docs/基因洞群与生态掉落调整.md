# 基因、洞群与生态掉落调整

## 交付边界

本轮修改基因、两种自然巨坑的布局、工蚁保底采收，以及木乃伊和侵蚀体死亡奖励。普通探索巨坑为 200×200，凝砂开局沿用选择的地图尺寸；祭坛任务地图和巨型墓葬不套用分层洞群。

完成 Release 编译和静态检查，未启动 RimWorld、未执行地图模拟或压力测试。此前版本已部署到 Steam 本地 Mods，后续按参考图调整的洞群入口见 [斜向河谷洞群实现与验收](斜向河谷洞群实现与验收.md)，部署状态以对应交付消息为准。没有提交或推送。编译保留既有 MSB3270：项目 MSIL 与 HarmonyMod AMD64 架构不一致。实际观感、地图种子适配和供需平衡仍待人工验收。

新布局仅影响新生成地图，不重塑旧地图；不会批量替换旧存档人物已保存的基因。菌巢不向旧地图补生。

## 基因

`1.6/Defs/Genes/NingshaRace_Xenotype.xml` 将 `AptitudeTerrible_Crafting` 换为 `AptitudePoor_Crafting`。

- 手工技能修正从 −8 变为 −4，保留热情。
- 原版“手工无能”本身并不是禁用手工工作的开关，不额外解除背景故事、健康等原因造成的工作限制。
- 使用原版代谢数值，不补偿新旧基因代谢效率的差异，不改变背景故事。

## 洞群与水系

配置入口：`1.6/Defs/DesertPit/MapGeneration/Maps/NingshaRace_LayeredLayout.xml`，由普通巨坑和开局巨坑共同继承。普通入口的 `portal.pocketMapSize` 为 200。

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `mainRadiusX` / `mainRadiusZ` | 34～40 / 28～34 | 二百格地图上的主洞室半径 |
| `centralRoomCount` | 6～8 | 中央周围连接的小洞室数量 |
| `smallRoomRadius` | 9～14 | 中央侧室、连续连接洞室的半径 |
| `secondaryRoomRadius` | 18～24 | 两处次要洞室半径，必须小于主洞室 |
| `linkRoomCount` | 3～5 | 每个次要洞室通往中央的交错洞室数 |
| `innerBoundary` / `outerBoundary` | 1/3 / 2/3 | 内层与中层、中层与外层的分界 |
| `antPreferredLayer` | 0.59 | 两座蚁巢优先落在的中层位置 |
| `riverWidth` | 3～5 | 河流完整宽度，允许配置三至八格 |
| `riverBankWidth` | 2 | 水面两侧预留的干燥岸宽 |
| `mainDryRadius` | 12 | 中央出生干地半径，允许十二至二十格 |
| `extraMoundsPerRoom` | 0～3 | 每处次要洞室独立抽取的可选菌巢数 |
| `moundSpacing` | 12 | 菌巢中心间的最小间距 |

洞层用相对地图半宽、半高的最大归一化距离计算，是三层同心方形，不是九宫格。洞室尺度乘以 `Clamp(地图短边 / 200, 0.75, 1.5)`；蚁穴建筑、储藏环、菌床和原有遮挡隧道的必要净空不缩小。

生成顺序：

1. 规划主洞室和中央侧室，保护出生干地与各洞室核心。
2. 提前规划斜向曲流，保留完整水面和河岸；中层蚁巢避开这条水系并分居河谷两侧，保留曲折单入口和厚岩脊。
3. 河流经过主洞侧面，通过连续曲线连接相对两边；河心主轴单调，不复用蚁巢的最短路算法。
4. 在两处中外层交点附近安置次要洞室，以宽窄变化的洞口连接两岸交错洞群，继续向外层延伸，并生成离开河谷的支洞。对应数量及轮廓参数见斜向河谷文档。
5. 核对洞室与蚁巢连通、单入口岩壁、河流端点及出生干地，再生成实际岩顶、岩墙与地面。
6. 水文步骤以顺序 250 绘制连续浅河，先于顺序 300 的出口及后续场景散布。浅水可涉过，河岸可行走。
7. 生成原有三处保底菌巢、入口驱蚁桩，再尝试额外菌巢；植物和蚁狮等后续步骤沿用已有保护检查。

河心、浅水和完整河岸在 `DesertPitLayoutData` 中分别记录。河岸及水面加入场景保护区，避免塌岩、地标、植物覆盖；水文步骤直接读取水面集合，不因步行通道标记跳过某段河水。驱蚁桩允许使用出生干地预留区，但仍检查实体占用和通路。

自然洞室使用坐标扰动、偏心凸湾和缓变岩壁，去除孤立轮廓边角；相邻洞群用平滑弯曲、宽窄变化的洞口连接，并限制实际地面重叠。蚁巢保持原有细长、回弯且遮挡视线的通道，两种连接方式不混用。

中央菌巢与两处蚁巢配对菌巢保持不变；每个次要洞室分别等概率抽取 0、1、2、3 处，理论总数为 3～9。可选菌巢必须位于对应洞室的真实干地，建筑完整落地，周围至少有 36 格可用菌床空间；不足时汇总一条警告并减少可选数量。每处仍沿用至多 24 株、最小间距 1.5 格、每 5000 tick 至多补生 3 株的稀疏配置。

源码入口为 `DesertPit/Generation/Config`、`Topology`、`Hydrology` 及 `DesertPit/Ecology/Generation/SecondaryFungalMounds.cs`。布局候选有限，洞壁形状在候选间复用，按结构分段交还生成帧；没有线程池中的地图写入、无限重试或运行时性能基准。

## 工蚁采收

配置入口：`1.6/Defs/DesertPit/AntColony/NingshaRace_DesertPitAntNest.xml`。

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| `harvestRadius` | 16 | 以所属蚁巢为中心的圆形采收范围 |
| `harvestMinGrowth` | 0.9 | 最低成熟度，同时遵守植物原版采收门槛 |
| `harvestReserveMultiplier` | 2 | 低于保底口粮乘以此倍率时才安排采收 |

优先级为：现有战斗、撤退、进食、休息等行为 → 搬运食物 → 缺粮采收 → 搬运贵重物资 → 巡逻。成熟度 89% 不采收，90% 且原版允许采收时才合格；只采收健康、实际产出食物且产物非药品的植物。木材、药材和没有食物产出的植物不参与。

植物候选按每座巢的局部圆形范围缓存，每 250 tick 随既有物资刷新周期更新。任务选择与执行使用同一组巢群、范围、驱蚁保护、有效植物及储藏空间条件。工蚁独占预留植物，结算前再检查一次。

`YieldNow()` 决定真实收成，因此菌巢内生菌仍有原有四倍加成；`PlantCollected()` 决定收获后重长或销毁。产物落地、进入现有搬运与进食流程，不自动收割满熟植物，不凭空增加营养。保留搬运批次和冷却限制，采收动作不重复计算一次搬运次数。

## 死亡掉落

| 生物 | 权重 | 物品 | 数量 |
| --- | --- | --- | --- |
| 凝砂木乃伊 | 80 | 活铁 `Bioferrite` | 12～30 |
| 凝砂木乃伊 | 15 | 生菌 `RawFungus` | 20～35 |
| 凝砂木乃伊 | 5 | 沙之热 `NingshaRace_SandHeat` | 10 |
| 侵蚀体 | 80 | 活铁 `Bioferrite` | 25～50 |
| 侵蚀体 | 20 | 沙之热 `NingshaRace_SandHeat` | 15 |

两张表各自权重总和为 100，每次只选一项，整数数量包含上下限。XML 配置位于木乃伊种族和凝砂族种族的 `CompProperties_DeathLoot.entries`；凝砂族额外指定 `requiredMutant=NingshaRace_ErosionBodyMutant`，普通凝砂族不掉落奖励。

`Loot/Components/CompDeathLoot.cs` 接入原版死亡的 `GetAdditionalLeavings(KillFinalize)`。原版负责放置实际物品，无全局死亡补丁；保存 `deathLootSettled`，同一生物最多结算一次。原版已用生物编号隔离遗留物随机状态，不另外重置随机种子。

已删除侵蚀体原来的固定 `Plasteel ×8`。`Plasteel` 是塑钢，不是活铁；新奖励不叠加这份旧物品。倒地、删除、消失、销毁尸体不产生奖励，复活后再次死亡不重复结算；正常地图死亡不要求玩家最后一击。保持原有尸体规则，不扩展地图外死亡掉落。

## 人工验收清单（未执行）

1. 新工匠背景凝砂族具有手工才疏、保留热情，能做满足技能门槛且未被其他原因禁用的手工工作；旧人物基因不自动替换。
2. 普通入口首次进入得到 200×200 巨坑；凝砂开局地图尺寸不被改成固定二百格。检查主洞开阔、6～8 个侧室、两处较小次要洞室、沿斜河展开的连续洞群及外侧支洞。
3. 两座蚁巢处于中层不同半边，洞口曲折、无法洞外直射蚁穴，完整岩层无第二入口；储藏环、伴生菌巢不被岩墙或水覆盖。
4. 河流连接相对两边并经过主洞侧面，全程浅水连续、岸线可走；场景全部生成后仍未被堵住。出生点、三名成员、物资及离洞绳处于干地，可立即移动和返回地表。
5. 保底菌巢三处保留，次要洞室各为零至三处，间距至少十二格，单处菌子仍稀疏。可选位置不足时只警告一次，不让开局失败。
6. 巢旁放置 89%、90%、100% 植物，分别检查十六格内外、病害、药材、原版成熟门槛和驱蚁保护；只有合格食用植物才被采收。
7. 同时提供外部食物、成熟植物和贵重物资，工蚁优先搬食物；无可搬食物且缺粮才采收，库存充足或储藏满则不采收。检查独占预留、途中开启驱蚁桩、植物被其他人收走及任务取消。
8. 采收产生真实产物并搬入库，菌巢收成加成不重复计算，植物按原版规则重长或消失；采收期间存读档不会重复产物。
9. 击杀木乃伊和侵蚀体，只出现对应表的一种奖励，数量不越界；不出现额外八个塑钢。普通凝砂族、倒地、删除或尸体清理不触发奖励。
10. 死亡前后存读档、复活后再次死亡不重复奖励。任务地图布局、巨型墓葬布局、原有蚁狮及吐酸蚁行为不受本轮布局分支影响。

少量人工样本不要求严格符合百分比；概率表以代码互斥逻辑与 XML 权重核对为准。编译通过不等于上述运行时项目已通过。

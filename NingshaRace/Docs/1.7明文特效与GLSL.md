# 1.7 RimUnity 资源与特效

凝砂 1.7 使用 RimUnity 标准导出资源和 ChezhouLib 1.7。预制体由 CL 的 RimUnity 适配模块挂载，Shader 和置换图通过 RimUnity 资源加载器加载，再向 CL 登记现有资源键。运行目录不包含凝砂的 AssetBundle，也不使用旧的 CL 粒子配方或凝砂专用 GLSL 转换器。

## 导出约定

源工程为 `E:/mygame/NingshaRace`，使用 Unity 2022.3.35f1，Package Manager 引用 `E:/RimModDev/RimUnity/UnityPackage`。`Tools/Build/NingshaRimUnityExport.cs` 逐项调用 RimUnity 的 `PrefabExporter.Export`；资源描述、依赖、材质、纹理和 GLSL 都由标准导出器生成，统一写入 `1.7/Data/RimUnity/catalog.json` 及其资源文件。

共 25 个顶层导出入口：19 个 Shader、4 个运行预制体和2张置换图。其他材质、网格和纹理作为依赖自动导出。三个 `BladebearerBloom*` Shader 不导出，辉光使用 RimUnity 自带系统。

| 逻辑路径 | 用途 |
| --- | --- |
| `Shaders/<源文件名>` | 角色、武器、粒子等 Shader |
| `Bundles/ningsharace/Assets/Prefabs/VFX/SandThrowBurst.prefab` | 沙瓶攻击 |
| `Bundles/ningsharace/Assets/Prefabs/VFX/PetrifyingSandwave.prefab` | 石化砂潮主体 |
| `Bundles/ningsharace/Assets/Prefabs/VFX/PetrifyingSandHit.prefab` | 石化命中 |
| `Bundles/ningsharace/Assets/Prefabs/VFX/qinshiyanwu.prefab` | 侵蚀体头部烟雾 |
| `Textures/MeleeFlameDisplacement` | 近战刀光置换图 |
| `Textures/BladebearerDisplacement` | 拥刀者置换图 |

`Defs/Core/NativeAssets/NingshaRimUnityPrefabs.xml` 使用 `ClAssetLord.rimUnityBundle` 与 `unityAssetMount`。`NingshaNativeResourceProvider` 在 CL 建立材质模板之前加载标准 Shader 和纹理，通过 `HostAssets` 共享底层资源，保留 Shader 默认参数、采样方式和原资源键。

## 粒子与辉光

技能和侵蚀烟雾实例化导出的 RimUnity 预制体，保留源层级、曲线、粒子模块和材质。沙瓶原有的尺寸 0.7、发射速率 0.55、爆发数 0.65、透明度 0.45 与水平面片设置在实例上应用，不改导出的原始资源。两组砂潮的容器根节点没有粒子组件，播放时从各自顶层粒子启动；事件子发射器由 RimUnity 管理。

一次性效果由地图组件按技能寿命销毁。侵蚀烟雾继承最终头部姿态，整体缩放 0.15，在死亡、离图、失去侵蚀状态或地图移除时销毁。实例不写入存档。

拥刀者火焰、火星及发光部件使用 Layer 28，统一进入 RimUnity Bloom。强度、阈值、柔和度和扩散使用 RimUnity 设置。普通身体和深度遮挡仍在原层。外观编辑器通过 `RimUnity.Rendering.BloomPreview` 复用同一套 Bloom 管线；凝砂 1.7 不编译旧版 Bloom 缓冲、模糊或合成代码。

## 界面底纹

砂岩与流沙 Shader 先通过 Graphics.Blit 生成离屏纹理，再交给普通 GUI 绘制，因此保持世界网格导出配置。宿主普通 IMGUI 纹理采样器固定为 ClampToEdge，直接提交超出 0～1 的 UV 不会按纹理 Repeat 设置平铺。NingshaTiledTexture 在 1.7 将面板和边带拆成 UV 单元内的矩形，保留比例、流沙相位、边缘翻转及 GUI 裁剪，避免末行末列像素被拉成横竖条纹。1.6 仍使用原始 GUI 绘制。

## 构建

加载顺序为 Harmony → RimUnity → ChezhouLib → 凝砂；HAR 也必须先于凝砂。使用与游戏 1.7 匹配的 HAR，启用面部动画时还需匹配版本的 Facial Animation。CL 主程序集不直接依赖 RimUnity，其 `1.7/RimUnityCompat` 由加载配置按前置条件启用。

首次导出或源资源改变时执行：

```powershell
& 'E:\RimModDev\NingshaRace\NingshaRace\Tools\Build\Export-RimUnity.ps1'
```

该入口启动后台 Unity 批处理，完成后退出。压缩纹理读回需要图形设备，因此不使用 `-nographics`。导出结果记录在 `Tools/Build/RimUnity-export-report.json`，失败会使构建终止。

随后编译并静态核对：

```powershell
& 'E:\RimModDev\NingshaRace\NingshaRace\Tools\Build\Build-1.7.ps1'
& 'E:\RimModDev\NingshaRace\NingshaRace\Tools\Build\Build-1.7-Assets.ps1'
```

构建合入共用内容，去掉从 1.6 复制的旧 AB 加载 Def，保留 1.7 的 RimUnity 挂载 Def。资源检查使用 RimUnity 自带 ShaderTool inspect，不启动游戏。发布资源可用 RimUnity `Tools/ResourcePacker` 整理，不能手改清单或另建资源格式。发布时必须携带标准资源目录及更新后的 RimUnity、CL 1.7 和凝砂程序集。

本次完成标准导出、必要编译及静态资源检查；未启动游戏，不将这些检查视为游戏内显示验证。

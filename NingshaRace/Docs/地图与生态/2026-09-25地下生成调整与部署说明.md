# 2026-09-25 地下生成调整说明

更新日期：2026-09-25。原始需求截图日期：2026-09-18。本文记录地底生成规则与相关问题处理，附录保留已有 CL 编辑器操作说明。

## 地底生成

| 项目 | 当前实现 |
|---|---|
| 洞室连接通道 | 每条通道独立记录有序中心线与实际占地，扣除洞室、蚁巢、水系和出生保护区；交叉格按记录顺序归属首条通道。各通道每 100 格目标为白晶砂芽与紫辉花簇菌合计 3～12 株、晶体 1 个，沿中心线分区放置；空位不足时按实际容量减量 |
| 蚁巢连接口 | 每个蚁巢通道接入主洞的位置，半径 7 格内目标为一簇黄绿晶卵草 3～5 株、浅青伞菇 9～13 株；空位不足时按原配额比例减量 |
| 河流岸线 | 保留贯穿河心与最低三格河宽，在水岸格坐标上叠加连续噪声，两岸独立产生凹凸与局部宽窄变化；由实际水面向外保留至少两格基准干岸 |
| 生态水潭轮廓 | 保留原有水潭生成概率和基准半径范围，使用随机朝向、不等长轴、宽缓浅湾与细部噪声；去除孤立水格，水面不覆盖洞壁干岸和通行保护格 |
| 沿河沼泽 | 每片半径从 4～10 调为 8～15；通过空间噪声排序划分约 80% 沼泽、20% 岩石地面，按实际格数取整 |
| 石林 | 每图 11～13 片，单片半径 9～13 格；柱石配额以 42～62 个为基准，乘以半径 r 与 r−1.5 范围内的有效干地面积比，四舍五入，保持扩大后的密度 |
| 主次洞室边缘 | 主洞及两处次要洞室分别统计距离真实岩壁六格内的干地，重叠格只算一次；沿洞壁周向分区，在普通植物与石林之后，每 100 格目标追加钟乳石 10～18 个、晶体 2～3 个；空位不足时按原配额比例减量 |
| 普通散布密度 | 普通植物目标 140～210 株，食用菌保底 48～64 株、药用菌保底 12～20 株；散饰按原 105～155 个基础配额抽取类别，仅复制钟乳石配额，骨骸不翻倍，普通晶体仍最多 1～3 个 |
| 地下树木与草 | 地下号角树、地下棕榈树及地下草的最低和最佳光照均为 50%；在水潭三格岸带以树木 4～8 株、地下草 max(4, 岸带格数 / 2) 株为目标，空间不足时按合规落点实际数量生成，不中断后续步骤 |
| 巨菇生态 | 标准 200×200 地图独立生成巨木伞菇 18～28 株、坠萤巨伞菇 12～18 株，按地图面积缩放并分区散布；分别产木材和坠萤果，缺失后接入现有每 15000 tick 最多补生一株的调度 |
| 生态洞室天光 | 每个非沼泽生态洞室固定生成 3～7 处天光裂隙，不受坠砂或水潭概率影响；优先沿水潭岸带以最远间距分散选点，无水潭时在干地分散放置 |

面积按每条通道、每个主次洞室的实际格数独立计算，份数为 ceil(面积 / 100)。例如三条各 40 格的通道分别计一份，共三份；单条 120 格通道计两份，每份分配 60 格。101 格分成 51 格和 50 格，避免最后一格单独承担整份资源。零面积不产生配额，恰好 100 格只计一份。通道两种植物的数量合计计算，各份随机数量独立抽取。

生成数据中的独立通道记录不写入存档，原有 PassageCells 合集继续服务于场景保护。洞壁面积先去重和分区，再排除通行保护格作为落点，已有植物及装饰占地不缩减面积配额。普通散布、蚁巢连接口、通道及洞壁追加资源分别计数，因此全图最终资源总量不以原来的两倍为上限。

石林有效面积采用相同的洞穴、干地和保护区条件，已有装饰不会改变参考面积。放置时仍遵循原有造型权重和间距，空间不足时报告目标数与可用格数。

天光生成后、生态植被放置前，以及树木生成后放草前，通过 DesertPitGenerationLighting 调用原版 GlowGridUpdate_First 刷新光照。地图绘制分区尚未创建时，仅跳过本次光照刷新的 WholeMapChanged 通知，真实光照计算完整执行；地图初始化收尾时由原版统一重建绘制网格。树草使用 GroundGlowAt 的实际结果筛选：低于 0.5 排除，恰好 0.5 接受。岸带目标数量在筛选亮度之前确定，实际数量受光照、肥力、占用与间距约束；资源生成结束后再次刷新并检查已放置树草的光照。

植物步骤内部依次生成生态植被、蚁巢连接口与通道资源、普通植物、巨菇、洞壁追加资源。巨菇不占用普通菌群配额，采收与补生默认参数见[巨菇与坠萤果生态说明](2026-09-25巨菇与坠萤果生态说明.md)。水潭仍沿用原有条件概率，不要求每个生态洞室都有水潭；坠砂裂隙继续使用既有的空间约束散布规则。

通道菌株及蚁巢连接口菌群在岩石等低肥力落点生成时，会给该格铺设沙土沉积作为生长基底。沼泽中的 20% 岩石采用湿地砂岩定义，复用原版粗糙岩石外观，提供 15% 肥力供紫辉花簇菌生长；菌株不生成在沼泽水面、浅水或河水上。晶体、钟乳石和植物均不覆盖已有实体。

根据 2026-09-25 后续确认，通道、蚁巢连接口和洞壁资源在合法空位不足时按实际容量生成，不扩大通道、不移到其他分区，也不因此中断生成。零空位直接跳过；通道至少一格时先放一枚晶体，其余空位放菌株。连接口植物按目标比例分配，至少两格时保留两类植物，单格优先浅青伞菇；洞壁钟乳石按比例向下取整，余量分配给晶体，各类数量不超过原目标。减量记录为普通日志，包含区域、目标数、实际数及合法空格数。天光、树草的实际光照要求和其他生成配额保持原有规则。

地图生成规则用于新生成地图，不改造已经存在的地图。地下树木的光照定义调整也会影响已有树木；低于 50% 光照时停止生长，需要天光裂隙或人工照明。

生态区域中的岸带树木、地下草和沼泽菌群同样按实际容量生成。数量目标为 8、最终选出 6 个合规落点时生成 6 株；没有合规落点时跳过该类植物，保留洞室、岸带与水潭，并继续后续植物和资源生成。仅记录包含区域、目标与实际数量的普通日志，不产生容量不足红字或黄字；不会降低 50% 光照阈值、压缩间距或覆盖实体。

## 河流与水潭的边缘噪声

河流的基准完整宽度仍为 3～5 格，先用缓变噪声控制沿程宽度，再以水岸格自身坐标叠加三层连续噪声，形成左右不对称的凹岸、凸岸和浅湾。最低河心半径保持为基准最小河宽的一半，外缘可以超出基准最大宽度；出生绕行距离同时包含最大扰动，水格另行排除出生干地。

河岸从最终连通水面向外扩展，保证基准两格干岸，并对外侧岸线增加少量宽度变化。完整水系占地仍在蚁巢选址前登记，后续洞群和场景按最终占地避让。

生态水潭以实际洞壁允许的半径为基准，随机选择朝向，长轴半径为基准的 1.05～1.18 倍、短轴为 0.78～0.96 倍。沿角度采样连续噪声并叠加宽缓起伏，边缘形成不等大的湾口与突出部。同一方向使用一致边界，避免逐格随机挖空潭内。外缘受真实洞室地面限制，紧邻洞壁的一圈地面保留为干岸；裁切后仅保留靠近潭心的四邻接连通水面。

岸带三格范围、天光选点、岸边树草均继续使用最终水面集合，不以旧的圆形半径推算。沼泽的 80% 湿地比例不受这次河流和水潭轮廓调整影响。

以下参数位于布局配置中：

| 参数 | 默认值 | 含义 |
|---|---|---|
| `riverEdgeNoise` | 1.1 | 河流边缘相对基准半径的最大扰动格数，允许 0～1.5；向内扰动受最低河宽限制 |
| `habitatPondEdgeNoise` | 0.28 | 水潭边界相对椭圆半径的最大扰动比例，允许 0～0.45 |

噪声和连通整理只在新地图生成期间执行，不增加地图运行时轮询，不改造已有河流或水潭。随机岸线外观尚未进行游戏内验证。

## 附录：已有 CL 屋顶编辑操作说明

在 CL 实体地图编辑器的“素材放置”栏进入“屋顶”页：

1. 选择天花板、薄岩顶、厚岩顶或稳定厚岩顶，使用笔刷或矩形直接绘制。
2. 点击“拆除屋顶”后，点击或框选要移除的区域。
3. 使用“查看屋顶”显示彩色覆盖层，可切换为只查看所选类型；界面显示鼠标所在格的实际屋顶名称。
4. 每次拖动为一条撤销记录，支持撤销、重做及保存到地图模板。

视图颜色：人工天花板为绿色，薄岩顶为黄色，普通厚岩顶为灰色，稳定厚岩顶为蓝色。目录包含已加载模组的屋顶定义，包括凝砂的稳定厚岩顶；CL 自带 `CL_StableRockRoof`，可在没有凝砂族的项目中使用。

## 验证范围

### 2026-09-25 地形生成日志诊断

检查 `Player.log` 中本次地下开局的生成异常，确认两处独立问题：

- 附属洞室通道直接把蚁巢的 ExternalAccessCell 作为寻路终点。该格虽在蚁巢外，四邻格仍可能处于保留占地内，不满足通道净空，导致布局步骤中断。接入点现沿目标所在的已有四邻接洞地选取，起点、终点和寻路统一使用相同的净空条件；雕刻仍避开完整蚁巢及保留生态区。
- 生成步骤提前刷新光照时，原版首次刷新会通知尚未创建的地图绘制分区，触发空引用。生成专用光照入口保留原版计算，只在当前地图尚无绘制分区时延后对应的光照绘制通知，不修改光照阈值或减少植物配额。

首轮日志中的洞壁距离缓存缺失及钢铁矿脉无法放置发生在布局中断后，属于后续生成步骤使用不完整地图产生的连锁错误。随机状态栈不平衡也与原版生成步骤捕获异常后未执行该步骤的 PopState 相符。处理首发原因，不为空洞缓存填默认值。

00:41 的后续日志已不再出现上述寻路和光照空引用，暴露出的错误为“通道 4 分区 1，位置 (117, 0, 84)，目标 10 个资源、可用 3 格”。此前按百格向上取整计算目标，却强制要求每个局部分区有足量空位；极短的通道残余区域或已有占用会触发异常，导致整个植物步骤提早退出。本次按用户确认调整为按空位生成，并处理零空位时的晶体索引边界，继续执行其他分区、普通植物和洞壁资源。

河谷小洞室属于允许随空间减量的可选结构，其结果在必要布局通过连通检查后记录为普通日志。布局失败仍报告异常，不以日志等级调整代替必要结构检查。

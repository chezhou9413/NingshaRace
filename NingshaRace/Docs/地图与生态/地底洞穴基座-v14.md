## 已接入的地形

- 巨湖、汇流、分汊三个 v14 预设，按游戏地图的生成种子选择模板；实际种子、模板和尺寸写入游戏日志。
- 主洞与外围支洞、带穿水代价的连接树、少量短回路。
- 锚点固定的自然曲线、独立左右宽度和岸带、宽入流口、出界支流和截流水坑。
- 多尺度凹凸洞壁、偏心叶瓣、岩柱；不包含 v15 之后的小墙壁算法。
- 岩体、沙地、洞壁附近的粗砂岩地面、浅水、深水、厚岩顶。
- 近、远两个干燥末端洞室及弯折洞颈。保留实际路径距离约束，生态步骤将完整巢群安置在实际洞室内。
- 在算法选定的入口干地放置返回出口，周围半径三格的现有干地固定铺沙，并避开后续生态铺土、菌床和植物；不改变洞壁与水面。

移植保留阶段散列和 Mulberry32 随机流、归一化几何、Float32 距离场及四方向格网距离。无需浏览器或 JavaScript 运行时。现有入口仍生成 200 × 200 地图，算法按实际尺寸栅格化；目前要求正方形地图。

## 分区生态

沿用实验台 `oasis.js`、`lighting.js` 的默认参数：绿洲腹地、湿润岸带和疏草边缘；主河前 55% 的连续受光段及与其相接的入流；较大半数截流水潭与绿洲中央光斑；亮区外围的灰暗过渡和最多三处独立灰暗区。剩余可达干地为深暗洞穴，蚁巢洞室独立保留。

| 区域 | 地面和植被 | 建筑与景观 |
| --- | --- | --- |
| 绿洲腹地与湿岸 | 土壤、富土；地下草、原版灌木、地下号角树与棕榈，黄绿晶卵草、浅青伞菇 | 中央天光、公共菌床、入口驱蚁桩 |
| 绿洲边缘与背光地 | 草地逐渐稀疏，背光处以凝砂菌类和巨菇替代需光植物 | 保留入口周围空地 |
| 受光河岸与水潭 | 土壤、草灌、少量树木和黄绿菌草 | 天光裂隙、稀疏发光晶体 |
| 灰暗区及外缘 | 菌砾斑块、紫辉花簇菌、原版 Agarilux、白晶砂芽与巨菇 | 钟乳石、少量落沙 |
| 深暗洞穴 | 沙地和菌砾斑块；蓝灰洞杯菌、浅青伞菇、原版 Glowstool/Bryolux，稀疏巨菇 | 钟乳石与落沙；绿洲外宽敞干地配置两个地热喷泉、一个油砂渗洞 |
| 近、远末端洞室 | 独立菌床与巢群食物 | 完整蚁巢、蚁后、成员及实体储藏 |

天光由现有光源建筑产生，种植检查使用真实 `GlowGrid`。凝砂五类菌草耐受天光；原版洞穴菌继续保留遇光死亡机制，只种在没有非菌类光照的地面。树木和巨菇保留四格间距，避让洞颈、预留路线、入口、能源点与巢区。生态地面只替换已有干地，不覆盖水域或重新雕刻岩壁。

河流、湖泊和水潭沿实际水面形成约一至三格宽的连续岸带。贴水处交替形成沙地和淤泥，较湿外缘过渡为湿润土壤，较干外缘夹杂沙砾；低频噪声让同类岸段成片分布，宽度自然变化。岸带沿地面延伸并被岩壁截断，受保护通道仍铺沙。菌床铺土和能源建筑避让岸带，淤泥不生成植物，其他岸带小型植被密度降至所属群落的 35%，不生成树木或巨菇。

各物种以实际初始数量建立补生上限，围绕同类原生位置补生，且持续检查保存的群落边界、光照、树木净空和玩家建造区域。

当前不执行游荡动物、蚁狮、鱼群、矿脉、遗迹、祭坛和墓葬入口生成。原生随机植物密度保持零，避免绕过分区规则。玩家开局人物与物资仍由原有开局逻辑安置。

## 实现入口

`1.7/Source/NingshaRaceLib/DesertPit/Generation/CaveBase/` 保存纯几何算法，`Generation/Regions/` 保存绿洲和明暗分区算法。`Steps/GenStep_DesertPitCaveBase.cs` 将地形写入地图，`Steps/GenStep_DesertPitRegionalEcology.cs` 完成生态填充。阶段之间使用现有增量生成流程交还主线程。

v14 对入口干地、截流洞室和近远末端洞室有严格净空要求。无法满足的种子会明确报错，不偷偷更换种子或切回旧算法。尚未通过游戏运行验证，不能据编译成功判断所有种子的生成成功率。

# 凝砂 1.7 构建

运行内容与权威源码均在 `1.7/`。不再支持 1.6，也不再从旧目录复制源码或覆盖 1.7 资源。

在仓库根目录执行：

```powershell
pwsh -NoProfile -File NingshaRace/Tools/Build/Build-1.7.ps1 -Configuration Release
```

需要 .NET 10 SDK、RimWorld 1.7 的 Waylith 程序集，以及对应版本的 Harmony、ChezhouLib、RimUnity、HAR 和可选 FA 编译引用。默认路径在 `1.7/Source/Directory.Build.props`；CL 和 RimUnity 根目录可通过构建脚本参数传入。

主程序集输出到 `1.7/Assemblies`，FA 扩展输出到 `1.7/Compat/FacialAnimation/Assemblies`。运行依赖由各自 Mod 提供，不复制到凝砂的 Assemblies。

只改 C# 或 XML 不需要重新导出图形资源。完整运行资源保留在 `1.7/Data/RimUnity`。项目内的素材导出、Shader 导出和离线特效预览脚本已移除；编译使用现有资源，不会重新生成贴图或特效。

静态检查资源可执行 `NingshaRace/Tools/Build/Build-1.7-Assets.ps1`。资源结构与后续维护方式见 [1.7 明文特效与 GLSL](1.7明文特效与GLSL.md)。

本地部署入口是仓库根目录的 `deploy_modSelf.bat`，它仅部署已编译内容，不重复构建。编译和部署前需关闭游戏。

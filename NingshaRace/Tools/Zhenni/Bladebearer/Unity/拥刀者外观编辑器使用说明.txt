震尼拥刀者外观编辑器

近战动画现为独立通用框架，使用同一 Pawn 上的“近战动画编辑器”入口。
四向握点、镜像刃口、动作与刀光在近战编辑器中设置；本窗口只负责分层外观。
完整说明见 Tools/Combat/MeleeAnimation/近战动画框架使用说明.txt。
工程目录与 Def 前缀已迁入 Zhenni/Bladebearer；旧测试单位需要重新生成，不迁移旧存档。

一、打开
启用更新后的凝砂族 Mod、现有依赖和游戏开发者模式。
调试动作菜单 → NingshaRace → 生成震尼拥刀者（敌对异常），然后点击可站立的地图位置。
选中震尼拥刀者，点击“震尼拥刀者外观编辑器”。单位属于 Entities 敌对阵营，会持刀自动追击附近敌人；暂不加入事件或墓葬遭遇。
四向均使用独立的头盔、盔甲、披风、火焰躯体、火苗和星光图层，火焰置换、动态火星、辉光及柔和闪烁共用正面的渲染方案。
四向素材来自 D:/QQ/刀兵测试 (4).psd；头部横向星光使用新版图层直接替换，左侧头盔补绘保持独立。斧头用于独立的震尼持斧者。
左右侧面分别使用原图，不自动镜像；预览顶部可切换正面、右侧、左侧、背面。
角色主体可见高度约 1.51 格，与成年凝砂族标准发型的约 1.53 格接近；不把火星和横向光束计入身高。正面后方的独立鬼火已从默认部件中移除。

二、编辑部件
左侧列表只显示当前预览朝向及四向共用的部件，从前到后排列，勾选框控制显隐。单独查看只影响当前编辑的拥刀者。
顶部正面、右侧、左侧、背面按钮同步切换预览和列表，并优先选中对应的同一部件；四向共用武器粒子不会被隐藏。
列表顶部的“全部 / 粒子”切换全部部件和仅看粒子；窄窗口也可使用同一筛选。
“新增紫色粒子”在当前朝向创建独立发射器：选中火焰时直接创建，否则弹出当前朝向火焰列表。默认跟随所选火焰的波动，位置、方向、颜色及粒子参数均可单独修改。
新建火星默认每秒 18 个，寿命 2.4 秒，细小紫色亮芯和尖尾，路径带噪声扭动；可以复制，或者用“删除新增粒子”删除。默认内置发射器只允许隐藏或调参。
“适用朝向”决定该部件出现在哪个方向，“全部”用于四向共用的刀刃、刀上火焰和火星。
“绑定”分为身体与武器握持。武器位置相对于装备贴图中心，默认 (0, 0)，局部层级为 0～20。原版负责瞄准角与镜像，通用近战框架将真实刀柄对齐四向握点并叠加动作，刀刃、火焰与火星跟随同一最终矩阵。
刀刃原图朝上，equippedAngleOffset 为 25 度（90 度贴图方向补偿加原版短刀的 -65 度持握倾角）；不要再给刀刃、火焰或火星单独添加相同的角度补偿。
刃口沿刀身局部 X 轴镜像翻面，与原版东西朝向镜像叠加；刀上的火焰和火星共用此翻转，不改变刀尖指向或持握角度。
匕首包含刀身、上段火焰、下段火焰及两组动态火星，共同跟随真实装备的持刀与攻击方向。两团火焰的根部、飘动和火星分别调整。更换绑定后需检查局部坐标，跨绑定的火焰跟随会解除。
选中部件后，在预览中按住左键拖动位置；画框表示原始贴图画布，透明区域也可拖动。
火焰的绿色方点是固定根部，橙色方点是原图尾端；两点决定原图固定范围。
青色箭头表示实际飘散方向，拖动箭头末端可独立调整角度，不移动根部和尾端。
滚轮缩放，右键拖动平移。“复位视角”恢复初始视角。
“前移一层 / 后移一层”调整相同朝向、相同绑定内的遮挡顺序。“复制选中火焰”可创建额外火苗，副本可以删除。
匕首、头部、胸前、披风、下摆各有独立动态粒子部件；选中后可以单独显隐、拖动、缩放、旋转、调整层级或复制。
原“匕首火星”静态底图不再绘制；列表中的“匕首动态粒子”表示持续发射器。
四向 PSD“特效”层使用新版连续横向星光，直接替换对应朝向的旧星光贴图；保留原 RGB、透明度和柔和闪烁参数。动态火星分别跟随当前朝向的火焰。
分层默认部件以“右侧 / 左侧 / 背面”开头，对应独立 id 后缀 _East / _West / _North。新增火星使用独立 PurpleSparks id，默认只在创建时的方向出现；可在“适用朝向”中调整，武器默认部件仍为四向共用。
侧面保留各自原图，背面火苗1、火苗2、火苗3分别接入独立火焰及跟随火星，位置和方向按原稿设置。披风覆盖躯体和火苗，头盔覆盖背后的星光；火星从可见火焰边缘、披风与下摆飘散。
头盔、身体、刀刃默认写入实体轮廓深度；其余火焰保留透明叠加。
位置和画布宽高以地图格为单位。部件围绕画布中心旋转。
小窗口使用“部件列表 / 参数调整”页签，参数和列表可滚动。

三、火焰参数
选中火焰后，“飘散偏转角”位于参数区顶部，可直接拖滑条或输入角度。
飘散偏转角：0° 沿根部到尾端方向，正值逆时针，负值顺时针，范围 -180° 到 180°。
偏转角同时转动传播、摆动和二维破碎位移，保留根部固定范围；“部件整体旋转”用于旋转整个贴图。
传播速度：置换纹理沿青色箭头方向滚动的速度。
横向 / 纵向摆幅：UV 位移强度，可以使用负数反向。
根部固定比例：靠近根部的多少范围保持稳定。
尾端位移曲线：控制根部到尾端的幅度变化。
波动密度、细节比例：控制整体弯曲与局部扰动。
二维置换破碎强度 / 密度：通过空间错位拉出断口、细丝和分离火苗，不进行噪声透明度擦除。
动画相位：给复制的火焰设置不同数值，可以错开动作。
根部和尾端必须分开，不能重合。红框数字尚未应用，悬停可查看允许范围。
“暂停”只暂停当前刀兵的效果预览时钟，游戏本身在窗口打开时暂停。

动态粒子：绿色点是发射点，橙色点与青色箭头决定飘散方向，两条淡青色线表示扇形散开范围。
头部、胸前和下摆默认向右上方飘散，披风默认向左下方；匕首粒子沿刀刃火焰方向。
“每秒数量”控制持续发射频率，设为 0 后现有粒子自然消失；“存活秒数”控制消失时间。
“跟随火焰”选择提供波动节奏的火焰部件：共用它的置换图、传播速度、密度和相位，粒子位置与飘散方向仍独立控制。
默认对应：匕首 → 匕首火焰，头部 → 火焰 1，胸前 → 火焰 3，披风 → 披风，下摆 → 火焰 4。
选择“独立节奏”时使用粒子自身的波动速度和相位；这两个参数位于“发射与路径细节”内。仍被粒子引用的火焰副本需先解除引用才能删除。
“飘散速度、粒子大小、散开角度”分别控制移动、尺寸和发射扇形；“发射范围、路径扭动幅度”在“发射与路径细节”中调整。
每颗火星拥有独立的连续噪声路径，横向弯曲并带少量纵向回旋，尖尾沿实际路径转向；不逐帧随机跳位，也不会在消失前被拉回原直线。
路径扭动快慢跟随所选火焰的传播速度，整体仍叠加火焰原有 RG 波动节奏。“路径扭动幅度”对应 particleSway，默认 0.03～0.045，设为 0 后沿发射方向直线飘散。
火星使用细长、不对称的亮芯与尖尾，朝向跟随实际飘动轨迹，离开火焰后逐渐减速、收细和熄灭。
默认尺寸为 0.010～0.014，多数火星比设定尺寸更小；辉光强度为 0.25～0.28。
约三成火星有更亮的亮芯，亮度逐颗随机；“火星亮度”控制该发射器的整体亮度，不会令整团一起明暗闪烁。
默认寿命参数为 2.2～2.6 秒，每颗实际寿命随机为参数的 75%～100%；前半段保留亮芯，后段才收细、冷却和淡出。
速度、大小、发射范围和路径扭动幅度以该部件画布为单位；颜色、透明度、辉光和层级仅影响所选发射器。
每颗粒子独立记录出生位置、速度和寿命，用刀兵时钟计算运动、摆动、缩小和淡出，不再依赖隐藏 Unity 粒子系统的播放状态。
低帧率或重新进入视野时按各自出生时刻恢复仍存活的粒子，不会因绘制间隔超过半秒而整批清空。
寿命、尺寸和发射方向影响后续新生粒子，原有粒子在自己的寿命结束后消失；亮度、摆幅和跟随火焰的波动参数实时生效。
更换跟随火焰时重建当前刀兵的粒子，避免混用出生时的波动；暂停预览同时暂停火焰和粒子。

四、颜色与深度
火焰原图保留明暗和透明边缘，原图 Shader 不额外增亮或采样扩散光晕。
火焰和原画加色光束在地图光照遮罩之后绘制，因此不受日夜与灯光遮罩染色；实体部件仍按原版光照绘制。
实体有效轮廓写入深度；火焰遵守深度测试和部件层级，不强制盖在所有物体上面。
没有抬高火焰的世界坐标，也没有关闭深度测试；透明空白不会挡住其他物体。
“光束叠加比例”用于原 PSD 的光束特效；普通火焰默认保持 0。
预览可切换深色 / 浅色背景；背景烘入预览纹理以正确显示原图光束的加色效果。
“后处理辉光”逐团调整：辉光强度为 0 时关闭该团辉光，默认 0.8；亮部阈值默认 0.5，越高越只保留最亮部分。
辉光参考 Rave 的选择性捕获、多尺度模糊与柔和合成流程，资源随凝砂族自身打包，无须安装 Rave。
地图捕获共享地图深度，编辑器捕获共享预览深度；原图与辉光使用相同的置换图、矩阵和动画时钟。
被完全遮住的火焰不产生辉光；可见火焰的光晕在屏幕空间向周围扩散。此效果不改变地面照明数值。

头部星光：在部件列表选择“头部星光”（原“光束特效”），顶部“星光与闪烁”可调基础发光亮度，默认 1。
闪烁幅度默认 0.18，亮度在基础值的 82%～118% 范围内连续起伏，保留常亮底光；幅度设为 0 时恢复常亮。
闪烁速度默认每秒 1.3 次，叠加较快的小幅变化；只调节 RGB 亮度，不改变透明度、位置和绘制深度，本体与辉光同步起伏。
后处理辉光强度和阈值默认 0.8 / 0.5，可以独立调节；暂停预览也会暂停闪烁。
星光位置按新版原稿对齐头部，左右延伸保留完整；绘制深度沿用现有部件层级，周围飘散火星由独立粒子发射器绘制。

五、导出与再次编辑
底部输入文件名，点击“导出 XML”。窗口显示实际导出目录，可用“复制目录”复制路径。
目录为游戏的 SaveDataFolderPath / NingshaRace / BladebearerPresets。
Windows 默认通常在：%USERPROFILE%\AppData\LocalLow\Ludeon Studios\RimWorld by Ludeon Studios\NingshaRace\BladebearerPresets
若游戏使用自定义存档路径，以窗口显示的目录为准。
“导入 XML”读取此目录中的文件。可以先把其他美工交付的 XML 复制进该目录。
导入失败会提示部件和字段原因，并保留当前草稿。
导出的部件字段与运行时参数一致，贴图通过 Mod 相对路径引用；XML 不内嵌 PNG。
facing 使用 South、East、West、North、All；attachment 使用 Body、Weapon。这两个字段均写入导出文件，缺失或非法时导入会明确报错。
lightFlickerStrength 保存闪烁幅度（0～0.5），lightFlickerFrequency 保存速度（每秒 0.1～5 次）；仅用于非火焰、非粒子的加色星光。预设省略幅度时保持常亮。
particleFlame 保存跟随火焰的部件 id，空值表示独立节奏；引用缺失或引用的不是火焰时，导入会明确报错并保留当前草稿。
此前导出的 XML 若没有 flowAngle 字段，导入时按 0° 处理；再次导出会包含当前角度。
没有 bloomIntensity / bloomThreshold 的已交付预设使用 0.8 / 0.5，再次导出会包含这两个参数。
没有 particle 标记的已交付预设，会把匕首火星贴图识别为独立粒子；缺少粒子参数时使用默认值。
lightIntensity 控制星光常亮亮度或火星亮度，缺少时按 1 处理。导入时舍弃此前的 twinkleFrequency / twinkleMin / twinkleMax，避免恢复整层闪烁。
particle 与 flame 不能同时为 true。粒子仅测试场景深度，不写入实体深度。
此前预设中的 emissionColor、emission、emissionThreshold、glow、glowRadius、glowSoftness 会在编辑器导入时舍弃，再次导出后可替换 Mod 外观 Def。
“恢复此部件初始参数”恢复打开窗口时的默认参数，或刚导入 / 刚创建副本时的参数。
关闭窗口后，该刀兵恢复 Mod 默认外观。草稿不写入游戏存档，请先导出需要保留的调整。

六、开发者接入
将导出 XML 替换到：1.6/Defs/Zhenni/Bladebearer/BladebearerAppearance.xml。
保留 defName = NingshaRace_Zhenni_Bladebearer_Appearance。替换原文件，不要另外添加重复 defName。
下次启动游戏时生效；只改这些参数不需要重新编译 DLL 或 AssetBundle。
PNG 位于 1.6/Textures/Zhenni/Bladebearer，四向身体部件均为 1024×1024 透明画布，保持相同位置和绘制尺寸。
置换图从 AssetBundle 读取，以保留线性颜色空间、Repeat、双线性采样及 Read/Write。新增置换图需要启用这些设置，重新打包并按名称选择。

七、构建维护
C# 工程：1.6/Source/NingshaRaceLib/NingshaRaceLib.csproj，目标 .NET Framework 4.8。
当前 Unity 编辑工程：E:/mygame/NingshaRace，Unity 2022.3.35f1c1，内置渲染管线。
Unity 菜单：RimWorldTools / 刀兵 / 构建 Windows Mod 资源。
批处理入口：NingshaRace.Zhenni.Bladebearer.Editor.BladebearerBundleBuild.BuildWindows。
构建包含 BladebearerFlame、BladebearerDepth、BladebearerParticles、BladebearerBloomSource、BladebearerBloomBlur、BladebearerBloomComposite 和置换图，输出 1.6/AssetBundles/ningsha_zhenni_bladebearer.ab。
Tools/Zhenni/Bladebearer/Unity 保存本次构建对应的 Shader、共用 include、置换图和构建脚本副本。
Unity 内的源文件是编辑入口，成功构建时同步这些副本，避免源码与资源包不一致。
恢复 Unity 工程时：把六个 shader 和 cginc 放入 Assets/Shader；置换图放入 Assets/Zhenni/Bladebearer/Textures；构建脚本放入 Assets/Zhenni/Bladebearer/Editor。
实体深度与颜色使用两个单 Pass Shader；原版即时绘制只执行 Pass 0，不要合并成依赖第二 Pass 的 Shader。
地图使用 MaterialPropertyBlock；即时预览另外同步专用材质，不要改回仅属性块方式。
后处理源码在 Zhenni/Bladebearer/Rendering/Bloom；地图使用 AfterForwardAlpha 捕获和 OnRenderImage 合成，窗口在 PawnCacheRenderer.OnPostRender 完成后处理专用预览。
动态粒子源码在 Zhenni/Bladebearer/Rendering/Particles；每颗粒子的出生位置、速度、寿命和大小分别保存，网格在 Pawn 原始矩阵下绘制。
地图与预览分别持有网格；粒子采用单 Pass，普通绘制与辉光捕获通过各自属性块切换，两者使用同一批顶点和深度测试，避免重复绘制亮部。
位置按出生位置、速度、逐渐减速的存活时间和噪声偏移计算；逐颗保留固定噪声种子及出生噪声值，以双通道 Perlin 噪声生成横向与纵向偏移，用同一路径的差分计算切线。
共用摆动、初速度与发射频率读取对应火焰的 RG 波动，每个发射器采样当前状态；每颗火星只额外计算数学噪声，不额外读取置换贴图。
粒子右侧常用参数直接包含飘散偏转角、每秒数量、速度、寿命、大小、亮度、散开角和噪声路径扭动幅度；“发射与路径细节”可输入发射点、方向基准和发射范围。
预览绿点调整发射点，青色箭头旋转飘散方向，橙点设置方向基准。修改方向影响后续新火星，已发射火星完成原路径后渐隐。
颜色区默认展开，支持 RGB 和透明度；“使用主体紫色”恢复紫焰配色并保留当前透明度。
新增、删除和四向粒子参数全部写入外观 XML，导入后立即预览。跟随火焰选择仅包含同朝向或四向共用火焰；跨朝向或跨身体 / 武器的引用在导出与导入时明确报错。

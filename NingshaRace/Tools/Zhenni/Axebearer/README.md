# 震尼持斧者

开发目录为 `E:\RimModDev\NingshaRace\NingshaRace`。持斧者拥有独立 ThingDef、PawnKind、外观、武器、渲染树和动作 Def，不覆盖拥刀者。

- 开发者菜单：`NingshaRace → 生成震尼持斧者（敌对异常）`；原版实体生成分类也可找到。
- 异常图鉴：高级异常，解除迷雾后发现；收容研究和逃脱规则沿用震尼系列。
- 斧头：36 点切割、40% 穿甲、2.8 秒原版攻击冷却。实际出招还包含前摇，冷却不等于整轮攻击间隔。
- 坠焰重劈、拧身横断、踏进压斩三套动作，完整播放 1.95～2 秒。抬斧蓄力约 0.8～0.98 秒，配合柔和紫色十字闪光预警；斧刃带动连续劈落，约在出招后 1.11～1.24 秒接触结算，随后压斧减速并缓慢收势。没有上挑、整圈翻转或命中停帧。
- 三套动作分别强调高举下劈、拧身横断与踏进压斩。侧面蓄力后仰、出手前倾；正背面分别配置握点移动和身体重心，西向与东向动作对称，保留各自原有握点和前后遮挡。紫焰斧光只在有效挥动段生成，持续 0.32～0.36 秒后淡出，回收阶段只保留逐渐消散的火星。
- 自动瞬移冷却 300 tick（5 秒），追击范围 3.5～12 格；当前攻击期间不抢占动作。死亡消散，无尸体，武器弃置销毁。

## 外观和特效

`1.6/Defs/Zhenni/Axebearer/AxebearerAppearance.xml` 保存独立的 56 个部件。身体复用拥刀者四向分层贴图，四向横向星光和背面三团独立火焰使用 `刀兵测试 (4).psd`；斧头取自同稿的斧头分组。背面火焰与各组跟随火星均可独立编辑。

斧头、斧刃火焰、动态火星使用同一 576×576 画布及装备变换。火焰沿用 RG 置换、固定根部、深度测试、忽略环境变色和选择性辉光；小火星沿火焰节奏和噪声路径飘动，不绘制静态火星底图。Shader AssetBundle 和紫焰斩光复用现有资源，不需要其他动画模组。

选中持斧者后，开发者 Gizmo 提供“震尼持斧者外观编辑器”和“近战动画编辑器”。可选择四向，调整部件与斧头握点、火焰方向、火星参数，添加紫色粒子；动作库、接触时间、前摇闪光、斧光宽度和寿命也可编辑并导出 XML。两类单位 Def 名不同，导入时会校验，避免相互覆盖。

外观组件的 `weaponPart=Axe` 指向实体斧头。`AxebearerMeleeAnimation.xml` 中 `grip` 为柄部握点，`bladeStart`、`bladeEnd` 为斧刃切削段；新增或调整特效无需修改 C#。数值伤害和冷却位于 `AxebearerWeapon.xml`。

## 素材维护

`Art/ExportAxe.py` 从 PSD 导出斧头和火焰，并按运行时配置生成静态图鉴及四向示意。显式传入 `--psd`、`--mod`、`--dependencies`；可选 `--preview` 指定示意图目录。`--create-appearance` 仅用于首次建立外观，文件已存在会明确报错；重导出素材时省略它，不覆盖美工参数。原始 PSD 和拥刀者配置保持独立。

图鉴彩图 `UI/CodexEntries/NingshaRace/Zhenni/Axebearer/Axebearer.png` 为 1024×1024。未发现图使用同路径的 `_Silhouette.png`，粗黑外轮廓、深灰填充和透明背景；生成提示存于 `Art/图鉴剪影提示.md`。
